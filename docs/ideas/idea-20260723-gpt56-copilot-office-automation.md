# 【初心者向け】ExcelやWordが勝手に動く？最新AI「GPT-5.6」搭載のCopilotで事務作業を自動化するプロンプト術

## 概要
Microsoft 365のCopilotに、OpenAIの最新フラッグシップモデル「GPT-5.6」が搭載されました。これまで以上に複雑な指示を理解し、Wordでの文書作成やExcelでのデータ分析を「ほぼ自動」でこなせるようになっています。初心者が「魔法のように」アプリを操るための、最初の一歩となるプロンプト集を紹介します。

## ターゲット
- 仕事でWord、Excel、PowerPointを使っているが、操作が苦手な初心者
- Copilotに頼んでも「期待通りの結果にならない」と諦めていた方
- 「最新のAI」を使って、定時で帰れるようになりたい事務職の方

## 導入のメリット
- **操作の自動化**: 「グラフを作って」「表をまとめて」と話しかけるだけで、面倒な操作をAIが代行。
- **指示の簡略化**: GPT-5.6の理解力により、細かい条件を言わなくても「空気を読んで」作業してくれる。
- **プロ級の成果物**: プレゼン資料の構成や、ビジネスメールの推敲が誰でも一瞬で完了。

## ステップ（導入ガイドの構成案）
1.  **GPT-5.6の凄さを体感**: 以前のAIと何が変わったのか、初心者が感じる「賢さ」の違い
2.  **Word編**: 白紙から「企画書の骨子」を10秒で作り上げるプロンプト
3.  **Excel編**: 「この表から異常値を見つけて」と頼むだけのデータ分析術
4.  **PowerPoint編**: 箇条書きを「見栄えの良いスライド」に変身させる指示の出し方
