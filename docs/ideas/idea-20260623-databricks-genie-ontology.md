# 【中級者向け】AIが「データの意味」を自ら学習！Databricks『Genie Ontology』導入ガイド

## ネタの概要
2026年6月の「Data + AI Summit」で発表された、Databricksの最新AI基盤『Genie Ontology』を活用したデータ分析術。
従来のAIが直面していた「社内用語やデータの文脈（コンテキスト）がわからない」という課題を、AIが自動で学習・構造化することで解決する。

## 中級者向けのポイント
- 単なる「プロンプトによる質問」から、AIに「ビジネス知識」を効率的に学習させる運用フェーズへのステップアップ。
- SQLやテーブル構造を知らなくても、AIが「データの裏にある意味」を理解して正確な回答を導き出す仕組みの解説。
- 50以上の業務アプリ（Slack, Jira, Salesforce等）と連携し、組織横断でインサイトを得る実践的なワークフロー。

## 導入ガイドの構成案
1. **なぜあなたのAIは嘘をつくのか？**：コンテキストの断片化問題
2. **Genie Ontologyの正体**：テーブル・ドキュメント・チャットから知識を自動抽出する仕組み
3. **実践！AIに「自社の常識」を教え込む方法**：タグ付けとドキュメント連携のコツ
4. **アクションまで自動化**：Genie Agentsと連携した「分析→報告」の自律ワークフロー構築
5. **ガバナンスと精度**：Unity Catalogによる安全なデータ利用と評価方法
