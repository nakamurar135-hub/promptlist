# 【中級者向け】会議の「発言」を即座に構造化！Google Docs Liveで実現する自律型ドキュメント同時生成ワークフロー

## 概要
Google I/O 2026で発表された「Docs Live」は、音声入力をリアルタイムで解析し、単なる文字起こしではなく、文書の構成（アウトライン）作成やトーン調整、さらには既存のDriveファイルやメールの情報を参照したドラフト作成を自律的に行う機能です。この機能を「執筆パートナー」として使いこなし、会議終了と同時に完成度の高い資料を仕上げるための中級者向けテクニックを紹介します。

## ターゲット
- 会議やインタビューの記録から素早くドキュメントを作成する必要があるビジネスパーソン
- 音声での思考整理（ジャーナリング）を構造化された文章に変換したいライター
- Google Workspace（Gmail, Drive）とAIの高度な連携を模索している中級ユーザー

## 紹介するプロンプトのポイント
- **「コンテキスト統合型アウトライニング」**: Docs Liveに対し、過去の関連メールや資料を特定し、それらとの整合性を取りながらリアルタイムで章立てを構築させる指示。
- **「トーン・トランスフォーメーション」**: 雑多な口頭発表を、特定の読者（上司、クライアント等）に合わせたプロフェッショナルな文体にその場で変換させるプロンプト。
- **「自律型リファレンス補完」**: 発言の中で触れられたデータや用語について、AIが自律的にWebや社内資料から情報を補完し、注釈やリンクを追加させるエージェント命令。
