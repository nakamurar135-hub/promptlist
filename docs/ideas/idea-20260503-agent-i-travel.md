# 2026-05-03: 【初心者向け】AIがあなたの代わりに「予約」まで完了！最新AIエージェント『Agent i』のおでかけプロンプト術

## 概要
2026年5月20日から提供が開始される統合AIエージェント「Agent i」の目玉機能「おでかけ」機能を先取りしたガイド。これまでのAIは「調べる」まででしたが、Agent iは「予約」までを代行します。PCやスマホでの複雑な予約サイトの操作が苦手な初心者でも、AIと会話するだけで旅行やディナーの計画が完結する未来の活用術を紹介します。

## ターゲット
- ネットでの宿泊予約やレストラン予約の操作が難しくて、いつも家族に頼んでいる人
- 複数のサイトを見比べて安いプランを探すのが面倒だと感じている初心者
- 「〇〇に行きたい」という曖昧な要望を、具体的なスケジュールに変えたい人

## ネタのポイント
- **「調べる」から「やる」へ**: 検索してURLをクリックして……という手間をAIが肩代わり。「予約までしておいて」の一言で完結する凄さ。
- **複数の機能を一括操作**: カレンダーへの登録、地図でのルート確認、予約確認メールの整理をAIが裏側で自動連携。
- **安心の「確認モード」**: 勝手に予約されるのが怖い初心者向けに、「最終確認のボタンを押すだけ」にする安全な使い方も解説。

## プロンプト例
- 「来週の土曜日に、横浜で美味しいイタリアンを食べたいです。予算は1人5000円以内で、空いているお店を3つ探して。気に入ったらそのまま予約までお願いね」
- 「家族4人で北海道旅行に行きたい。予算と日程を伝えるから、飛行機とホテルをセットで一番安いプランを探して、予約の準備ができたら教えて」
