# ネタ：【初心者向け】メールもSNSも「右クリック」で完成！Edgeの『AI書き換え』プロンプト術

## 概要
Microsoft Edge 124（2024年4月）以降に標準搭載され、2026年のアップデートでさらに進化した「AI書き換え（Rewrite with Copilot）」を、ITに疎い初心者向けに解説するガイド。ブラウザ上のメール作成画面やSNS投稿フォームで、書いた文章を右クリックするだけで「丁寧にする」「短くする」「熱意を込める」といったプロンプト（指示）をAIが自動実行してくれる便利さを紹介する。

## ターゲット
- メールの返信やSNSの投稿に時間がかかり、言葉選びに悩んでしまう初心者
- PCに備え付けのCopilotは知っているが、わざわざ別の画面を開いてコピペするのが面倒だと感じている層
- 「プロンプト」という言葉を聞くと、難しいコマンドを入力しなければならないと思っている人

## 記事の構成案
1.  **「書く」から「選ぶ」へ！**：Edgeブラウザが「AIライター」になる2026年の新常識。
2.  **コピペ不要！右クリックから「AI書き換え」を呼び出す**：
    - ブラウザの入力欄（Gmail、X、掲示板など）で文章を選んで右クリック。
    - 「書き換え」メニューからAIが提案してくれる。
3.  **初心者がすぐ使える！3つの「魔法のボタン」**：
    - **「丁寧にする」**：目上の人や仕事のメールに。
    - **「短くする」**：要点をパッと伝えたい時に。
    - **「熱意を込める」**：お礼や応援メッセージに。
4.  **もっとこだわりたい人のための「自由指示」**：
    - 「関西弁にして」「もっと親しみやすく」「3行でまとめて」といった、一言プロンプトのコツ。
5.  **「間違い」を恐れなくていい**：AIが下書きを作ってくれるから、自分は「選ぶだけ」でOKというマインドセットの提案。
