# 2026-05-04: 【初心者向け】AIがあなたの「作業員」に！ChatGPTの新アプリ『Codex』で面倒なファイル整理を丸投げするプロンプト術

## 概要
2026年5月に話題となっているChatGPTの新アプリ「Codex」を、ITが苦手な初心者向けに解説します。これまでのAIは「相談相手」でしたが、Codexは「実際に手を動かす作業員」です。バラバラの画像ファイルをPDFにまとめたり、大量のファイル名を一括で変更したりといった、PC操作に疎い人が苦労する「ちょっとした作業」を、プロンプト一つでAIに丸投げする方法を紹介します。

## ターゲット
- PCのファイル操作（名前変更、フォルダ分け、PDF化など）が苦手で時間がかかる初心者
- 「AIは文字で答えてくれるだけ」と思い込んでいる、ITに疎い層
- 仕事やプライベートで、スマホやデジカメの写真整理に困っている人

## ネタのポイント
- **「相談」から「作業」への進化**: ChatGPTは「教えてくれるAI」、Codexは「やってくれるAI」という違いを分かりやすく提示。
- **プロンプト不要の操作感**: 難しい指示は不要。「これ、いい感じに整理して」といった曖昧な指示でも、AIが中身を判断して動く凄さを伝える。
- **PCスキルの差を埋める**: フォルダ作成やファイル形式の変換など、初心者がつまずきやすい操作をAIが代行するメリットを強調。

## プロンプト例
- 「このフォルダにある旅行の写真を、日付ごとにフォルダ分けして名前を『2026_旅行_〇〇』に変えておいて」
- 「バラバラになっている5枚の画像を、1つのPDFファイルにまとめてダウンロードできるようにして」
- 「このExcel名簿から、住所が東京都の人だけを抜き出した新しいファイルを作って」
