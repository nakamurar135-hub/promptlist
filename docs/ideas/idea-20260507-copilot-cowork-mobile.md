# 【初心者向け】PCがなくても仕事が終わる！スマホ版「Copilot Cowork」で外出先からAIに仕事を丸投げする術

## 概要
2026年5月、MicrosoftのAIアシスタント「Copilot Cowork」がiPhoneやAndroidスマホに対応しました。
これまではPCの前でしかできなかった「過去のメールから要点をまとめる」「会議の予定を調整する」「資料の続きを作成する」といった複雑な指示が、スマホアプリからチャット感覚でできるようになります。
「プロンプト」という言葉を知らなくても、移動中や家事の合間に「あの件、よろしく」と頼むだけでAIが裏で動いてくれる、新しいAIの使いこなし術を解説します。

## ターゲット
- PCを開くのが面倒、または外出が多くてPCを触る時間がない人
- 仕事の連絡がスマホ中心で、AIをどう活用すればいいか悩んでいる人
- 「AIエージェント」という言葉は難しそうだが、便利な秘書は欲しい人

## キーポイント
1.  **スマホが「魔法の杖」に**: アプリを開いて「来週の会議の資料、これまでのメールを元に下書きしておいて」と話しかけるだけで、PC側のアプリ（WordやOutlook）で作業が進む。
2.  **「 Cowork（コワーク）」の凄さ**: 単なる質問回答ではなく、あなたの代わりにメールやファイルを探して「実際に作業を進めてくれる」のが最大の特徴。
3.  **初心者のための「丸投げ」プロンプト例**:
    - 「今日のメールの中で、私が返信しなきゃいけないものを3つ教えて」
    - 「〇〇さんとの打ち合わせの要点を、後でPCで読めるように保存しておいて」
    - 「移動中に思いついたこのメモを、報告書の形式に整えておいて」
