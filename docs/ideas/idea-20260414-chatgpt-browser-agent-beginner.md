# 【初心者向け】もう予約サイトを巡らない！ChatGPTの『ブラウザ自動操作』で宿探し・出張計画を丸投げするプロンプト術

## 概要
ChatGPTの新機能「ブラウザ自動操作（エージェント機能）」を活用し、ユーザーの代わりに宿泊予約サイトを横断検索させ、最適な宿の提案から空室確認までを自動で行わせる活用ガイド。

## ターゲット
- 旅行や出張のたびに、複数の予約サイトを自分で開いて比較するのが面倒な初心者。
- ChatGPTは「文章を書くもの」だと思っており、外部サイトの操作までできることを知らない人。

## プロンプトのポイント
- 「〜のサイトで調べて」「空き状況を確認して」という具体的な操作指示。
- 予算や立地、譲れない条件（禁煙、朝食付きなど）を一度に伝える「わがままオーダー」プロンプト。
- AIが提案したリンク先で、最終的な予約をスムーズに完了させるための連携方法。
