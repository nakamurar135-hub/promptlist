# 【初心者向け】YouTubeが「物知りな先生」に！新機能『Ask YouTube』で知りたい情報を一瞬で引き出すプロンプト術

## 概要
2026年5月、Google I/Oにて発表された「Ask YouTube」は、動画の内容をAIが理解し、対話形式で質問に答えてくれる画期的な機能です。長い動画を最初から最後まで見る必要はなく、「この動画で一番大事なポイントは？」「〇〇の手順だけ教えて」と聞くだけで、必要な情報にたどり着けます。本記事では、初心者がYouTubeを「動画サイト」から「学習・解決ツール」へと進化させるための具体的なプロンプト術を解説します。

## ターゲット
- 忙しくて長い動画を見る時間がない方
- 料理やDIYの手順など、特定のシーンだけを素早く知りたい方
- 英語の動画や専門的な内容を、分かりやすく噛み砕いて教えてほしい初心者

## 記事のポイント
1. **動画の「つまみ食い」視聴**: 動画全体を要約させ、必要な部分だけを特定する方法。
2. **「やり方」の即時抽出**: 複雑な手順動画から、箇条書きでステップを書き出させる指示。
3. **理解を深める深掘り質問**: 動画の内容に基づいた「なぜ？」「具体的には？」という追加質問のコツ。
4. **学習効率の最大化**: 複数の関連動画から情報を集約し、自分専用のまとめを作る方法。

## プロンプト例
- 「この動画の内容を、3つのポイントで短くまとめて教えて」
- 「この料理動画で使われている材料と、下準備の手順だけリストアップして」
- 「このガジェットレビュー動画で、結局『買い』なのか『見送り』なのか、その理由も含めて教えて」
- 「動画の中で説明されている専門用語『〇〇』について、小学生でもわかるように説明して」
