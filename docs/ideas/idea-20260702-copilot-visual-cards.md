# 【初心者向け】文字を読むのはもう終わり？Microsoft Copilotの『ビジュアルカード』で情報を一瞬で理解するプロンプト術

## 概要
2026年6月末、Microsoft Copilotのチャット回答が進化し、天気予報や株価、Plannerのタスクなどを「リッチな視覚カード（ビジュアルカード）」で表示する機能が強化されました。文字が並ぶだけの回答ではなく、図解やボタン付きのカードで結果を受け取ることで、ITに詳しくない初心者でも直感的に情報を把握し、次のアクション（予約やタスク追加）へ移れるようになります。

## ターゲット
- AIの回答が長文だと読むのが面倒に感じる初心者
- PCに標準搭載されているCopilotを、もっと「便利ツール」として使いこなしたい人
- プロンプトをどう書けば「見やすい結果」が返ってくるか知りたい人

## 構成案
1. **「文字だけ」から「見てわかる」へ**: 新機能ビジュアルカードのメリット
2. **一発でカードを引き出すコツ**: プロンプトに「表にして」「カードで出して」と加える魔法
3. **具体的な活用シーン**:
    - 「今週末の旅行先の天気を教えて」→ お天気カードで視覚的に把握
    - 「今日の予定とタスクを整理して」→ Plannerカードでそのまま操作
4. **初心者が陥る「長文回答」を防ぐ方法**: 短く、的確に指示を出す「引き算」のプロンプト術
5. **まとめ**: AIは「読むもの」から「見るもの」へ
