# ネタ：会議の「わからない」をその場で解決！PowerPointの最新AI『スライド解説』活用ガイド

## 概要
2026年6月に発表されたPowerPointの新機能、スライド上のテキストを選んでAIに解説させる機能を初心者向けに紹介。専門用語や複雑な図解を、発表者の手を止めずに自分だけでコッソリ解決する「聞き上手プロンプト」を提案する。

## ターゲット
- 会議中に難しい言葉が出てきても、恥ずかしくて質問できない初心者
- 大量の資料を読み解くのが苦手なIT・AIに疎い層
- Copilotを「資料作成」以外にどう使えばいいか分からない人

## 記事の構成案
1. **もう会議で置いていかれない！**：PowerPointの新機能「スライド解説」のニュース。
2. **「これ何？」をAIに聞くメリット**：
    - 発表者の話を遮らなくていい。
    - 自分のレベルに合わせて、噛み砕いて教えてもらえる。
3. **コッソリ解決！「聞き上手」なプロンプト例**：
    - 【用語解説】「このスライドの『〇〇』という言葉を、中学生にもわかるように説明して」
    - 【要約】「このスライドで一番伝えたいポイントを1行でまとめて」
    - 【背景】「このグラフが示している問題点は何？初心者向けに教えて」
4. **使いこなしのポイント**：
    - テキストを「選ぶだけ」で始まる、究極のカンタン操作。
    - AIの回答が正しいか、後で確認するためのメモ機能との連携。
5. **まとめ**：AIは「作る」だけでなく「理解を助ける」最強のパートナー。
