# 2026-05-25: 【初心者向け】AIの回答に「もう一回！」が言いやすく。Copilotの最新UIと『聞き直し』で正解にたどり着くプロンプト術

## 概要
2026年5月のアップデートで、Windows 11に備え付けの「Microsoft Copilot」の画面構成（UI）が刷新され、AIの回答に対して「別の言い方で」「もっと短く」といった再試行（Retry）がボタン一つで簡単に行えるようになりました。初心者が一度の質問で諦めず、AIを上手に「育てて」理想の回答を引き出すための『聞き直し』プロンプト術を解説します。

## ターゲット
- PCに最初から入っているCopilotを触ってみたが、一度変な答えが返ってくると「やっぱりAIは使えない」と諦めてしまう初心者
- 難しいプロンプトを考えるのが苦手で、もっと直感的にAIとやり取りしたい層
- スマホやPCの操作に自信がなく、なるべく少ない手間でAIを活用したい方

## ネタのポイント
- **「再試行ボタン」の活用**: 回答の下に新設されたボタンにより、プロンプトを打ち直すことなく「別の視点から」の回答を促せるようになった。
- **「聞き直し」は恥ずかしくない**: AIは何度聞き直しても嫌な顔をしないことを強調。初心者が陥りがちな「遠慮」をなくす。
- **文脈（コンテキスト）の維持**: 前の会話を踏まえたまま、特定の部分だけを修正させるプロンプトのコツ。

## プロンプト例
- （回答が出た後に）「今の説明、ちょっと難しいから『小学生でも分かる言葉』で、もう一度説明し直して」
- （回答が出た後に）「内容はいいけど、上司に送るメールにしたいから『もっと丁寧な敬語』に変えて」
- （回答が出た後に）「長すぎるから、大事なポイント3つだけに絞って、箇条書きで出し直して」
