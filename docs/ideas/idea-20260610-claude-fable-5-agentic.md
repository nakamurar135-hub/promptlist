# 【中級者向け】AIが「自己監査」して精度を高める！Claude Fable 5の『Agentic Judgment』活用ガイド

## 概要
2026年6月10日、Anthropicは最強モデル「Mythos」級の能力を一般向けに解放した「Claude Fable 5」を発表しました。最大の特徴は、AI自身が指示の矛盾を検知し、自律的にワークフローを修正する「Agentic Judgment（エージェント的判断）」機能です。本記事では、中級者向けに、Fable 5の「Effort Dial（努力ダイヤル）」を使いこなし、複雑なナレッジベースの監査や多段階の自律タスクを完遂させるプロンプト術を解説します。

## ターゲット
- 大規模なドキュメントやコードベースの品質管理を自動化したいエンジニア
- 従来のAIでは「指示通りに動かない」と感じていた高度な自動化を目指すユーザー
- Claudeの最新機能をいち早く業務に取り入れたい中級者

## 記事のポイント
1. **Agentic Judgmentの衝撃**: 指示を待つのではなく、ドキュメント間の矛盾を自ら発見し報告する「自己監査」能力。
2. **Effort Dialの最適化**: タスクの難易度に応じて推論コストと精度のバランスを調整するテクニック。
3. **ナレッジベースの自動監査**: 数百のルールファイル（CLAUDE.md等）を読み込ませ、矛盾や古い情報を一括クレンジングするワークフロー。
4. **「目的（Goal）」ベースのプロンプティング**: 手順の指示を捨て、ゴール設定だけでAIに最適なルートを選ばせる高度な指示法。

## プロンプト例
- 「このリポジトリ内の全設計ドキュメントを監査し、最新のコーディング規約と矛盾している箇所を特定して。修正案を提示するだけでなく、なぜそれが矛盾と判断されたかの推論プロセスも出力して。」
- 「/goal: 競合他社Aの製品アップデートを調査し、自社製品のロードマップとの競合リスクを分析せよ。Effort: Maxで設定し、ウェブ検索と内部ドキュメントを往復して、確証が得られるまで深掘りして。」
