# 2026-04-05: 「プロンプトを書く」はもう古い？2026年の新常識「コンテキスト・エンジニアリング」入門

## 概要
「毎回同じような指示を書くのが面倒」「プロンプトの正解がわからない」という初心者の悩みを、2026年の最新トレンドである「コンテキスト（文脈）の固定」で解決するガイド。
プロンプトを一から書くのではなく、AIに「自分の状況」をあらかじめ教えておくことで、一言の指示で期待通りの答えを引き出す方法を解説します。

## ターゲット
- 毎回「〜の立場で、〜のように回答して」と入力するのが苦痛になってきた初心者
- プロンプトの「書き方のコツ」を調べすぎて、逆に何を入力すればいいか迷子になっている人
- ChatGPTやCopilotを使い始めたが、返ってくる回答が一般的すぎて物足りないと感じている人

## 記事のポイント
- **「プロンプト」から「コンテキスト」へ**: 2026年は、命令文（プロンプト）を工夫するよりも、AIに背景情報（コンテキスト）をどう渡すかが重要。
- **「自分専用ボット」で指示を省略**: ChatGPTの「GPTs」やGeminiの「Gems」を使い、自分の仕事内容や好みの口調をあらかじめ設定しておくことで、日常の指示を「これお願い」レベルまで簡略化する方法。
- **「コンテキスト」を構成する4要素**:
    1. **役割（Role）**: あなたは何者か？（例：30年のベテラン秘書）
    2. **背景（Background）**: 今、どんな状況か？（例：急ぎの会議資料を作っている）
    3. **知識（Knowledge）**: 何を知っておいてほしいか？（例：過去の議事録の傾向）
    4. **形式（Output Format）**: どんな形で出してほしいか？（例：箇条書きで3点以内）
- **初心者が今日からできること**: 難しい設定は抜きにして、まずは「カスタム指示（Custom Instructions）」に自分のプロフィールを1行書くだけで劇的に回答が変わる体験を提案。
