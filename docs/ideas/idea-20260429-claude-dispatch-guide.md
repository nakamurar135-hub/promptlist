# ネタ：外出先からPCを操る！Claude新機能「Dispatch」による自律型リモートワーク術

## 概要
Anthropicが2026年4月28日に発表した新機能「Dispatch」にフォーカスした中級者向けガイド。スマホのClaudeアプリから自宅やオフィスのPC（Claude Desktop）に指示を飛ばし、ローカルファイルの操作や複雑なタスクを実行させる「リモート制御」の活用法を解説します。単なるチャットを超え、AIを「自分の代わりにPCで作業してくれるエージェント」として使いこなすための設定とプロンプト術を伝授します。

## ターゲット
*   外出先から急な資料修正やファイル確認が必要になるビジネスパーソン
*   PCでしかできない複雑なAIタスク（コード実行やローカルファイル分析）をスマホから指示したい中級者
*   「AIエージェント」の実践的な導入事例を知りたいユーザー

## 記事の構成案
1.  **Claude Dispatchとは？**：スマホがPCの「リモートコントローラー」になる仕組み
2.  **導入の準備**：Claude Desktopとモバイルアプリの連携、Max/Proプランの要件、PCの「スリープ無効化」の重要性
3.  **実践！Dispatch活用シーン**
    *   **クイック・プル**：外出先から「PCのダウンロードフォルダにある最新の提案書を要約して」と指示する
    *   **デイリー・ブリーフィング**：出勤前にSlackやカレンダーを巡回させ、PC上で作成したサマリーをスマホで受け取る
    *   **バックグラウンド・タスク**：スマホから重いデータ分析やコーディングをPCに投げ、結果だけを後で確認する
4.  **失敗しないための「エージェント指示」プロンプト**：PC内のファイル構造をAIに把握させ、正確に操作させるためのキーワード指定術
5.  **まとめ**：デスクに縛られない「AIファースト」な働き方の実現
