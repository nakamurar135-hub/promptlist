# 【初心者向け】PDFも動画も「聴いて」理解！Google NotebookLM『音声ポッドキャスト生成』活用術

## 概要
GoogleのAIノートツール「NotebookLM」の新機能「Audio Overview」を活用し、難しい資料や長いYouTube動画を、2人のAIが会話形式で解説するポッドキャストに変えるガイド。移動中や家事の合間に「聴くだけで」学べる活用法を提案。

## ターゲット
- 忙しくて長文の資料や動画をチェックする時間がない初心者
- 難しい専門用語を噛み砕いて説明してほしい人
- ラジオやポッドキャスト感覚で情報をインプットしたい人

## プロンプトのポイント
- 資料をアップロードした後、「会話を生成して」と1クリックで指示する方法。
- 特定のトピックに焦点を当てた会話にするための「ソースの絞り込み方」。
- AIが生成した内容が正しいか、元の資料（ソース）と照らし合わせる「ファクトチェック」の習慣化。
