# 【中級者向け】目に見えるものすべてが検索対象に！Google『マルチモーダル検索エージェント』活用ガイド

## 概要
2026年5月28日、Googleは「検索エージェント」の次なる進化として、テキストだけでなく動画やリアルの視覚情報をリアルタイムで解析し、実行まで繋げる「マルチモーダル検索エージェント」の一般公開を開始しました。カメラを向けるだけで「これの修理方法を調べて、必要な部品をAmazonでカートに入れて」といった複雑なタスクを完遂できるようになります。本記事では、この最新機能を使いこなし、日常のあらゆる課題を視覚的に解決するためのプロンプト術を解説します。

## ターゲット
- スマートフォンやウェアラブルデバイスでのAI活用を最大化したい方
- 言葉で説明しづらい「目の前の問題」をAIに丸投げしたい方
- 最新のマルチモーダルAI（Gemini 2.0等）の実践的な使い方を知りたい中級ユーザー

## 記事のポイント
1. **マルチモーダル検索の真価**: 静止画から「リアルタイム動画解析」へ。エージェントが「見ているもの」を理解する仕組み。
2. **コンテキストの自動補完**: ユーザーが言葉にしなくても、周囲の状況（場所、時間、対象物の状態）をAIが読み取る。
3. **視覚指示型プロンプト**: カメラ映像やスクリーンショットを起点に、具体的なアクション（注文、予約、修理ガイド作成）を指示する方法。
4. **プライバシーとセキュリティ**: 視覚情報をエージェントに渡す際の注意点と、安全な設定方法。

## プロンプト例
- 「（壊れた家電にカメラを向けて）この型番を特定して、故障原因として考えられるものを3つ挙げて。修理に必要な工具セットが手元にないなら、最短で届くものをピックアップして」
- 「（冷蔵庫の中身を映しながら）これらの材料で、15分で作れる低糖質な夕食レシピを提案して。足りない調味料があれば、買い物リストに追加しておいて」
- 「（街中の看板を見せて）このイベントのチケット予約サイトを探して、私のカレンダーの空き時間と照らし合わせて最適な時間を提案して」
