# 2026-07-04: 【初心者向け】「あの資料どこ？」をAIが秒で解決！Microsoft 365 Copilotの『自分専用検索』プロンプト術

## 概要
Microsoft 365 Copilotの最新アップデートにより強化された、社内・自分専用のデータ検索機能を初心者に解説するガイド。
PC内に保存したWord、Excel、Outlookのメール、Teamsのチャットなど、膨大なデータの中から「今必要な情報」を自然な言葉で探し出す、魔法のような検索術を紹介します。

## ターゲット
- 過去のメールや資料を探すのに、いつも何十分も費やしているPC初心者
- ファイル名や保存場所を覚えるのが苦手な人
- 「AIに自分のデータを見せるのは不安」だが、便利なら使ってみたいと思っている人

## 記事のポイント
- **「どこにあるか」を覚える時代は終わり**: ファイル名が分からなくても、「先週の会議で佐藤さんが言っていた資料」と聞くだけでAIが探し出します。
- **Microsoft Graph連携の凄さ**: Word、Excel、Outlook、Teamsを横断して情報を結びつけるため、アプリを切り替えて探す手間がゼロになります。
- **初心者でもすぐ使える3つの「探し物」プロンプト**:
    - **「記憶の断片から探す」**: 「6月頃に送った、出張の経費に関するメールの内容を教えて」
    - **「バラバラの情報をまとめる」**: 「プロジェクトAに関するチャットとメールの内容を、箇条書きで要約して」
    - **「関連資料を一括表示」**: 「明日の会議に向けて、前回の議事録と関連するExcel表を準備して」
- **プライバシーも安心**: 「自分のデータはAIの学習に使われない」という法人向け・個人Pro版の安心ルールを、初心者に分かりやすく解説。
