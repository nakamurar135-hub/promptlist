# 【中級者向け】ブラウザが「知能」を持つ時代へ！Chromeの『組み込みAI（Built-in AI）』活用ガイド

## 概要
2026年5月26日、Google I/O 2026にて、ChromeブラウザにGemini Nanoを直接組み込んだ「Built-in AI」の最新API群が発表されました。これにより、クラウドへの送信なしに、ブラウザ上で要約、書き換え、翻訳、さらには構造化データの抽出が完結します。本記事では、開発者だけでなく一般ユーザーも恩恵を受けられる、ブラウザの「ローカルAI」を使いこなすためのプロンプト術と活用法を解説します。

## ターゲット
- プライバシーを重視し、機密データをクラウドに送りたくないビジネスパーソン
- オフライン環境でもAIの支援を受けたいノマドワーカー
- ブラウザの標準機能を拡張して、自分専用の作業環境を構築したい中級ユーザー

## 記事のポイント
1. **Built-in AIの3大メリット**: 「プライバシー保護」「オフライン動作」「ゼロ・レイテンシ」がもたらす新しいWeb体験。
2. **Summarizer & Writer APIの活用**: 閲覧中のページを瞬時に要約し、その場で返信メールやブログ記事のドラフトを作成する方法。
3. **Prompt APIによる「ブラウザ操作の自動化」**: JSON Schemaを用いた構造化出力により、Webサイト上の情報を正確に抽出・分類するテクニック。
4. **ハイブリッド運用のススメ**: 高度な推論が必要な場合はクラウド（Gemini Pro）、定型作業はローカル（Gemini Nano）と使い分けるプロンプト戦略。

## プロンプト例
- 「（Summarizer APIを使用して）この長文記事の要点を3つの箇条書きでまとめて。特に『今後の展望』に関する記述を重点的に抽出して」
- 「（Rewriter APIを使用して）このメールの下書きを、より丁寧かつ熱意が伝わるビジネス敬語に書き換えて。分量は元の1.5倍程度で」
- 「（Prompt APIを使用して）この製品レビュー一覧から、ポジティブな意見とネガティブな意見を抽出し、以下のJSON形式で出力して：{ 'sentiment': 'positive/negative', 'reason': '...' }」
