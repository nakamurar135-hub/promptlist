# 【初心者向け】LINEがあなたの秘書になる！新AI『Agent i』で失礼のない返信・誤字脱字をゼロにするプロンプト術

## 概要
2026年5月上旬、LINEヤフーはトーク画面で直接AIがサポートする新機能「Agent i（エージェント・アイ）」を一般公開しました。入力欄に現れるAIアイコンをタップするだけで、相手のメッセージに合わせた返信案の作成や、自分の書いた文章の誤字修正、さらには「敬語への変換」などが瞬時に行えます。「AIは難しそう」と感じている初心者でも、いつものLINE操作の延長で最新AIの恩恵を受けられる活用術を解説します。

## ターゲット
- LINEの返信内容にいつも悩んでしまう人
- 敬語の使い方に自信がなく、目上の人への返信に時間がかかる人
- 外出先で急いで返信し、誤字脱字をしてしまいがちな人
- AIを使ってみたいが、専用アプリを入れるのは面倒だと感じている人

## 記事のポイント
1. **Agent iの基本操作**: トーク画面に現れた「AIアイコン」の正体と、オン・オフの切り替え方法。
2. **「代筆」の極意**: 相手の長文メッセージをAIに読み取らせ、3パターンの返信候補から選ぶだけの時短術。
3. **トーン変換プロンプト**: 友達向けのタメ口で書いた下書きを、一瞬で「失礼のない丁寧なビジネス敬語」に変えるテクニック。
4. **誤字脱字の自動検知**: 送信前にAIにチェックさせることで、うっかりミスを防ぐ安心設定。

## プロンプト例
- 「（相手のメッセージを受けて）承諾する方向で、かつ体調を気遣う一言を添えた返信案を作って」
- 「この文章を、もっと柔らかい表現の敬語に直して：『明日の会議、10時からで大丈夫ですか？遅れないでください』」
- 「以下の下書きに誤字脱字がないか確認して、あれば修正したものを提示して：『お世話になります。明日の件、了解致しました。宜しくお願いいします。』」
