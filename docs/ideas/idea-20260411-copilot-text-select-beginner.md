# ネタ：【初心者向け】全部読まなくてOK！Copilotの新機能『テキスト選択』で、知りたい部分だけをAIに聞く時短プロンプト術

## 概要
2026年3月にMicrosoft 365 Copilotに導入された「テキスト選択とグラウンディングの拡張」を、PC操作に不慣れな初心者向けに解説するガイド。長い回答や文書の中から「ここだけ知りたい！」という部分をマウスでなぞるだけで、AIがその箇所に特化した説明をしてくれる機能を活用する方法を紹介します。

## ターゲット
- PCに備え付けのCopilotを使っているが、AIの回答が長すぎて結局どこを読めばいいか迷ってしまう初心者。
- 難しい言葉が出てくると、そこから先に進めなくなってしまうITに疎い層。
- 効率よく情報を整理したいが、複雑なプロンプトを考えるのが面倒な人。

## 記事の構成案
1.  **Copilotの回答が長すぎて困っていませんか？**：2026年3月の新機能で、Copilotが「あなたの指し示した場所」をより賢く理解するようになったニュース。
2.  **マウスでなぞるだけ！「ここだけ教えて」の魔法**：
    - 全体の要約ではなく、特定の段落や単語にフォーカスして質問できる。
    - 難しい専門用語をなぞって「これ、もっと簡単に言って」と頼む方法。
3.  **「選択して聞く」初心者向け鉄板プロンプト**：
    - **【用語解説】**：選択した箇所に対して「中学生にもわかるように、例え話で説明して」
    - **【具体化】**：選択した箇所に対して「これ、私の仕事（または家事）でどう役立つの？」
    - **【逆質問】**：選択した箇所に対して「これについて、もっと詳しく知るために、私は何をAIに聞けばいい？」
4.  **「全部理解しなきゃ」というプレッシャーからの解放**：AIとの付き合い方は「つまみ食い」でいい、という新しい活用スタイルを提案。
5.  **まとめ**：マウス操作一つで、Copilotはあなたの「専属家庭教師」に変わる。
