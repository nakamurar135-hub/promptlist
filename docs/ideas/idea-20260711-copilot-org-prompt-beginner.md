# 【初心者向け】もう「プロンプト」で迷わない！会社のルールに合わせた回答が届く『組織プロンプト』活用術

## 概要
AIを使いたいけれど「なんて指示すればいいかわからない」「会社で推奨されている使い方がわからない」と悩んでいませんか？Microsoft 365 Copilotの新機能『組織プロンプト』を使えば、システム管理者が用意した「正解のプロンプト」をワンクリックで呼び出せるようになります。初心者がプロンプト作成の壁を乗り越え、社内の定型業務をAIで劇的に効率化するための活用ガイドです。

## ターゲット
*   PCに備え付けのCopilotを使い始めたばかりの会社員
*   プロンプトを自分で考えるのが苦手、または面倒だと感じている初心者
*   社内でのAI活用ルールが分からず、一歩踏み出せない人

## 記事のポイント
*   **「選ぶだけ」でプロ級の回答**：自分で文章を考えなくても、会社が用意したメニューから選ぶだけで最適な結果が得られる仕組みを解説。
*   **迷子にならない「共有プロンプト」の探し方**：Copilotの画面上で、どこから組織専用のプロンプトを呼び出すのかをステップバイステップで紹介。
*   **定型業務の「AI化」を体験する**：
    *   「週報の作成」「議事録の要約」「社内規定の確認」など、よくある業務をボタン一つで実行する流れ。
*   **プロンプトを「自分流」に少しだけアレンジ**：用意されたテンプレートに、自分の状況（日付や担当者名など）を付け加えるだけの「ちょい足し」テクニック。
