# 【中級者向け】AIがあなたのPCを直接操作！Copilot Studioの『Computer-using Agent』実践ガイド

## 概要
2026年5月27日、MicrosoftはCopilot Studioにおいて、AIが直接デスクトップアプリやWebサイトを操作する「Computer-using Agent」の一般提供を開始しました。APIが公開されていないレガシーな業務システムや、複雑なUI操作が必要な作業も、AIが画面を「見て」理解し、マウス操作やキー入力を代行します。本記事では、この革新的な機能を活用して、属人化したルーチンワークを完全に自動化するプロンプト術を解説します。

## ターゲット
- API連携ができない古い社内システムやWebツールの操作に時間を取られている方
- 複数のアプリを跨ぐ複雑な事務作業を自動化したいビジネスリーダー
- 「AIにPC操作を任せる」という次世代の自動化を先取りしたい中級ユーザー

## 記事のポイント
1. **Computer Useの衝撃**: 「API不要」の自動化。AIが人間と同じように画面上のボタンやフォームを認識して操作する仕組み。
2. **ワークフローとの融合**: 従来の「決定論的（手順通り）」な自動化と、AIによる「適応的（状況判断）」な操作を組み合わせる方法。
3. **安全な自動化の設計**: 認証情報の管理や、AIが予期せぬ操作をしないための「ガードレール」設定のコツ。
4. **実例：レガシーシステムへのデータ入力**: Excelから抽出したデータを、APIのないWebフォームへAIが自動で転記するワークフローの構築。

## プロンプト例
- 「このExcelファイルに記載された顧客情報を読み取り、ブラウザで社内管理システムを開いて、一人ずつ新規登録して。入力が終わるたびに完了メッセージを送って」
- 「指定したWebサイトから最新の競合価格を取得し、自社の価格改定案を作成して。その後、デスクトップ版のOutlookを立ち上げて、承認者にメールの下書きを作成して」
- 「（画面上のエラーメッセージを見て）このエラーの原因を特定し、マニュアルPDFを参照して解決策を試して。解決できない場合のみ、スクリーンショットを撮って報告して」
