# 【初心者向け】AIが「部下」のように動く！新機能『ChatGPT Work』で面倒な事務作業を自動化するプロンプト術

## ニュースの概要
2026年7月8日、OpenAIはChatGPTの新機能「ChatGPT Work」を発表しました。これは単に質問に答えるだけでなく、GoogleドライブやSlack、Microsoft Teamsなどのアプリと連携し、ユーザーの代わりに「仕事」を完遂してくれるエージェント機能です。デスクトップアプリを使えば、自分のPC内のファイルを使った作業も依頼できるようになります。

## 初心者へのメリット
- **アプリ間の移動が不要**: ChatGPTに頼むだけで、メールを読んで予定をカレンダーに入れ、返信の下書きを作るところまで一気に終わります。
- **「予約」ができる**: 「毎朝8時にSlackの未読をまとめて報告して」といった、定期的な仕事を任せられます。
- **話し言葉でOK**: 難しいIT用語を知らなくても、「これやっといて」という感覚で指示が通ります。

## おすすめプロンプト例
```text
@Outlook 昨日の午後に届いたメールを全部確認して、
急ぎで対応が必要なものを3つ選んで要約して。
そのあと、それぞれの返信の下書きをデスクトップの「返信待ち」フォルダに保存しておいて。
```

## ターゲット層
- 複数のアプリ（メール、チャット、Excelなど）を行き来して疲弊している人。
