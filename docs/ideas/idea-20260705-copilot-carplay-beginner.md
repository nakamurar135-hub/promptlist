# ネタ：運転中もAIがサポート！Apple CarPlay版Copilotで「話すだけ」のハンズフリー仕事術

## 概要
2026年5月に登場した「Apple CarPlay版Copilot」を、ITに疎い初心者向けに解説。運転中で手が離せない時でも、音声だけでメールの確認や返信、アイデアのメモができる「ハンズフリー・プロンプト」の基本を紹介する。

## ターゲット
- 普段からiPhoneを車に繋いで使っているが、AIは難しそうだと感じている人
- 移動時間が多く、車内での時間を有効活用したいビジネスマンや主婦
- 「プロンプトを打つ」のが面倒でAIを敬遠している初心者

## 記事の構成案
1. **車が「動くオフィス」に！**：Apple CarPlayでCopilotが使えるようになったニュースを紹介。
2. **「打つ」から「話す」へ**：
    - キーボード操作は不要。Siriのように話しかけるだけでOK。
    - 運転中でも安全に「指示」を出すための基本。
3. **今日から使える「車内専用」音声プロンプト**：
    - 【メール確認】「未読の重要メールを要約して教えて」
    - 【返信作成】「〇〇さんに『了解しました。詳細は後ほど送ります』と返信しておいて」
    - 【メモ】「今思いついたアイデアをメモして：〇〇の企画について…」
4. **安全に使うためのコツ**：
    - 画面を見ずに、音声の「聞き返し」を活用する。
    - 長い指示よりも、短い「お願い」を繰り返すのが成功の秘訣。
5. **まとめ**：移動時間を「削る」のではなく「活かす」AIの使い方。
