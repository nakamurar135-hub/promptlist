# ネタ：【初心者向け】「ググる」が「買い物代行」に！Google新検索ボックスと『Universal Cart』活用プロンプト術

## 1. ターゲット
*   ネットショッピングで「一番安い店」や「在庫のある店」を探すのに疲れている初心者
*   Google検索は使うが、AIがどう買い物に役立つかイメージできていない層

## 2. 元ネタニュース
*   Google I/O 2026にて発表された「25年ぶりの検索ボックス刷新」と「Universal Cart（ユニバーサル・カート）」。
*   検索、YouTube、Gmail、Geminiのどこからでも商品を一括管理。
*   AIが価格履歴、在庫状況、支払い方法の特典まで考慮してアドバイスをくれる。

## 3. 記事の方向性
*   「検索して、サイトに行って、カートに入れて…」という面倒なステップをAIが一つにまとめる利便性を解説。
*   「一番お得な買い方を教えて」という、初心者でも言えるシンプルなプロンプトの威力を紹介。
*   Google PayやWalletとの連携による、安全でスムーズな購入体験を強調。

## 4. プロンプトのポイント
*   **比較**: 「これとこれ、どっちが今の私にお得？」という比較プロンプト。
*   **監視**: 「安くなったら教えて」「在庫が復活したら教えて」というエージェント的指示。
*   **確認**: 支払い方法のポイント還元率をAIに計算させる聞き方。

## 5. 既存ネタとの差別化
*   `idea-20260620-ai-shopping-beginner.md`（AIショッピング）とテーマは近いが、本件はGoogle I/O 2026で発表された「Universal Cart」という「Googleの全サービス横断型」の新機能に特化。
*   既存のGoogle Search系（`idea-20260526-google-search-agent.md`など）は「情報収集」が主だが、本件は「購買（アクション）」にフォーカス。
