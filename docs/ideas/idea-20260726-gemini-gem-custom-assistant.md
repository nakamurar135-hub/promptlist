# 【初心者向け】AIを「自分好みの性格」に！Google Geminiの新機能『Gem』で作る専用アシスタント活用術

## 概要
AIに質問しても、いつも同じような「教科書通りの回答」でつまらない……。そんな悩みは、2026年7月に本格普及したGoogle Geminiの「Gem（ジェム）」機能で解決します。Gemを使えば、難しいプロンプトを毎回書かなくても、AIに「優しい料理の先生」や「ズバッと言ってくれる相談役」などの役割を覚えさせることができます。初心者でもボタン一つで呼び出せる、自分専用AIの作り方を解説します。

## ターゲット
- ChatGPTやGeminiを使ってみたが、回答が堅苦しくて馴染めなかった初心者
- 毎回「〜のように振る舞って」と指示を書くのが面倒だと感じている人
- ITやAIの仕組みは詳しくないが、もっと自分に寄り添った回答が欲しい層

## 記事のポイント
1.  **「Gem」はAIの着せ替え**: 指示すべき内容が最初から整理されている「Gem作成画面」の使い方を紹介。
2.  **プロンプトは「箇条書き」でOK**: 難しい文章は不要。「専門用語は使わないで」「いつも励まして」といった、自分の好みを伝えるだけの簡単設定。
3.  **ワンタップで起動**: 一度作れば、次からはリストから選ぶだけ。検索の手間も、指示の打ち直しも不要になる快適さを強調。
4.  **おすすめの「Gem」設定例**:
    - **「冷蔵庫の救世主」**: 余った食材を伝えると、即座に3つのレシピを出してくれる。
    - **「スマホの悩み解決隊」**: iPhoneやPCの操作で困ったとき、初心者向けに噛み砕いて解説してくれる。
    - **「やる気アップ応援団」**: 今日の目標を伝えると、ポジティブな言葉で背中を押してくれる。
