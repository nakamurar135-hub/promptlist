# 【中級者向け】チーム全員をAI使いに！Claude Code「/team-onboarding」活用ガイド

## 概要
Claude Code v2.1.101で追加された「/team-onboarding」コマンドを活用し、チーム全体のAI活用レベルを底上げするための導入ガイド。個人の「秘伝のタレ」になりがちなAIスキルやワークフローを、プロジェクト共通の資産として自動ドキュメント化し、新メンバーが即戦力としてAIを使いこなせる環境を構築する手法を解説する。

## ターゲット
- Claude Codeを個人で使いこなしているが、チーム展開に課題を感じている開発リーダー・PM
- チーム内のAI活用スキルの属人化を解消したい中級ユーザー

## 主な内容
1. **「/team-onboarding」の仕組み**: .claude/skills/やHooks、ワークフローをAIがどう解析し、ONBOARDING.mdを生成するか。
2. **共有資産の整備術**: チームで使い回せるカスタムスキルの書き方とディレクトリ構造（.claude/skills/review.md, deploy.mdなど）。
3. **自動生成ドキュメントのブラッシュアップ**: AIが生成したガイドを人間がどう補完し、チームの「標準プロンプト」として定着させるか。
4. **実戦ワークフロー**: 新メンバーがアサインされた際、コマンド一つで環境構築からAI連携までを完了させる手順。
