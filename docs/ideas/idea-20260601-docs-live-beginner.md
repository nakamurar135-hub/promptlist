# 【初心者向け】キーボード入力はもう古い？Googleの新機能『Docs Live』で「話すだけ」で完璧な書類を作るプロンプト術

## 概要
2026年5月のGoogle I/Oで登場した「Docs Live」は、従来の音声入力を遥かに超える「リアルタイム文書生成」機能です。単に声を文字にするのではなく、あなたが曖昧に話したアイデアを、AIがその場で構成を整え、プロ並みの文章へと仕上げてくれます。本記事では、PC操作に不慣れな初心者でも、スマホやマイクに向かって話すだけで報告書やメールを完成させる「未来の書き方」を伝授します。

## ターゲット
- キーボード入力が苦手、または時間がかかる方
- 頭の中にあるアイデアを文章にまとめるのが苦手な方
- 外出先や移動中に、声だけで素早く下書きを完成させたいビジネスパーソンや主婦の方

## 記事のポイント
1. **「箇条書きトーク」からの自動生成**: 思いついたことをバラバラに話しても、AIが論理的な文章に組み立てる仕組み。
2. **リアルタイム修正の魔法**: 「もう少し丁寧に」「ここは短く」といった声の指示で、その場で文章を微調整する方法。
3. **連携機能で時短**: 生成した文章をそのままGmailで送ったり、Googleドライブに保存したりするスムーズな連携術。
4. **「自分らしさ」の調整**: 話し方のトーンを指定して、親しみやすい文章や硬いビジネス文書を使い分けるコツ。

## プロンプト例
- 「今から話す内容を、上司への週報としてフォーマルな文章にまとめて（音声入力開始）」
- 「今の文章、もう少し親しみやすい表現に変えて。あと、最後に『よろしくお願いします』を付け足して」
- 「友達に送る旅行の計画案を作りたいから、今から話す行きたい場所をリストにして整理して」
- 「（話した内容に対して）この部分を強調して、読み手がワクワクするようなキャッチコピーを3つ提案して」
