# ネタ：【初心者向け】「あの時の写真」も「あのメール」もAIが即発見！Siri AIの『自分専用検索』プロンプト術

## 1. ターゲット
*   iPhoneやMacの中にデータが溜まりすぎて、必要な情報を見つけるのが苦手な初心者
*   「あの時、誰からどんなメールが来たっけ？」と、アプリを横断して探すのを面倒に感じている層

## 2. 元ネタニュース
*   WWDC 2026にて発表された「Siri AI」のパーソナルコンテキスト理解機能。
*   メッセージ、Eメール、写真などを横断的に検索し、ユーザーの「個人情報（文脈）」に基づいた質問に答える。
*   例：「先週末に撮った写真の中から、〇〇さんが写っているものを探して」「昨日届いたメールにある予約時間を教えて」といった指示が可能。

## 3. 記事の方向性
*   「検索窓にキーワードを入れる」から「Siriに記憶を呼び起こしてもらう」への変化を強調。
*   初心者が「自分の情報」をAIに効率よく探させるための、曖昧な記憶を補完するプロンプト術を紹介。
*   プライバシーを保護しつつ、デバイス内の情報をフル活用して「秘書」のように振る舞わせる体験を提案。

## 4. プロンプトのポイント
*   **時間と場所の指定**: 「いつ」「どこで」という記憶の断片を組み合わせて、検索精度を上げるコツ。
*   **人物と内容の紐付け**: 「〇〇さんからもらった」「△△についての」といった、複数の情報を掛け合わせる指示。
*   **横断的な依頼**: 「メールで来た予定をカレンダーに入れて」といった、検索からアクションへ繋げるフレーズ。
