# ネタ案: 【初心者向け】Wordが魔法のキャンバスに！AI画像生成と「賢さ」を選べる新機能活用プロンプト術

## ターゲット読者
- PCに備え付けのCopilotやChatGPTを使い始めたばかりの初心者
- 文書作成中に画像が必要になり、わざわざブラウザを開いて探したり生成したりするのが面倒だと感じている人
- AIの「モデル」という言葉は聞いたことがあるが、どう使い分ければいいか分からない人

## 記事の概要
2026年6月のアップデートでMicrosoft WordのCopilotが大幅進化。文書内で直接画像を生成できるようになったほか、用途に応じてAIの「モデル（賢さのレベル）」を切り替えられるようになりました。本記事では、初心者が「指示ひとつ」で文書にぴったりの画像を挿入し、かつ目的に合わせた最適な回答を得るための具体的なプロンプト手法を解説します。

## 主な内容
1.  **Wordから離れなくてOK！**：AI画像生成を文書内で完結させるメリット
2.  **「賢さ」を使い分ける**：スピード重視のモデルと、じっくり考えるモデルの切り替え方
3.  **伝わるプロンプトのコツ**：
    *   「〜の画像を作って」＋「雰囲気（ビジネス風、手書き風など）」の組み合わせ
    *   モデル切り替え時の「お願いの仕方」の違い
4.  **実践例**：企画書の表紙画像生成や、難しい規約の要約（モデル切り替え活用）
