# ネタ：【初心者向け】「説明」はもう不要！Copilotの新機能『Vision』で画面や現実をAIに「見せる」プロンプト術

## 1. ターゲット
*   PCやスマホの操作で分からないことがあっても、それを言葉で説明するのが苦手な初心者
*   エラーメッセージや複雑な図表を、AIにそのまま理解してほしいと感じている層
*   「百聞は一見に如かず」をAIで体験したい人

## 2. 元ネタニュース
*   2026年6月のMicrosoft 365 Copilotアップデートで発表された「Vision」機能。
*   PCの画面やスマホのカメラで映しているものをAIがリアルタイムで認識し、音声やチャットで質問に答える。
*   例：複雑なダッシュボードの解説、エラー画面の解決策、カメラで映した実物の操作方法などをAIが即座に回答。

## 3. 記事の方向性
*   「状況を文字で打つ」から「画面を見せて聞く」へのパラダイムシフトを強調。
*   初心者が「これ、どうすればいい？」と指をさす感覚でAIを使えるようになるための、視覚情報を活かしたプロンプト術を紹介。
*   プライバシーに配慮しつつ、AIを「隣にいる詳しい友人」のように頼る体験を提案。

## 4. プロンプトのポイント
*   **「これ」を指す指示**: 「画面のこの部分を解説して」「カメラに映っているこれの名前は？」といった、視覚対象を特定するフレーズ。
*   **状況の丸投げ**: 「今起きていることを説明して」「次は何をすればいい？」など、AIに判断を委ねる聞き方。
*   **マルチモーダルの活用**: 視覚情報に加えて「もっと簡単に」「図解して」と補足する、合わせ技のコツ。
