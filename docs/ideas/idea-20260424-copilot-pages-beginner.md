# 【初心者向け】調べ物から資料作成まで1画面で完結！Microsoft Copilotの『Pages』活用プロンプト術

## ターゲット
*   PCに備え付けのCopilotを使い始めたばかりの初心者
*   ネットで調べた情報をWordやメモ帳にコピペしてまとめるのが面倒だと感じている人

## 記事の狙い
Microsoft Copilotの新機能「Pages」を使い、AIが生成した回答を「使い捨て」にせず、自分だけのノートとして育てていく方法を解説する。ブラウザ上で完結する「AI時代の新しいメモ術」を提案する。

## ネタのポイント（ニュース性）
*   Microsoftが発表した、AIの回答を保存・編集・共有できる「Copilot Pages」。
*   一過性のチャットを、永続的なドキュメント（Pages）に変換できる。

## 初心者向けプロンプト例
*   「最新のAIニュースを3つ探して、それをPageにまとめて」
*   「旅行の計画を一緒に考えて。決まった内容はPageに保存して、後で編集できるようにして」
*   「このPageにある内容を元に、SNS用の告知文章を3パターン作って」

## 期待される効果
*   「AIの回答が流れていってしまう」という不満を解消。
*   コピペ作業を減らし、AIとの対話からそのまま資料の下書きを作成できる。
*   Microsoft 365（旧Office）ユーザーにとって親和性の高い作業フローを構築できる。
