# 【初心者向け】検索結果が「自分専用アプリ」に！Google検索の新機能『カスタムダッシュボード』活用プロンプト術

## 概要
「何度も同じことを検索する」のは、初心者にとって意外とストレスです。Google I/O 2026で発表された新機能では、AIが検索結果を元に「カスタムダッシュボード（ミニアプリ）」を自動生成してくれます。例えば「ダイエットの記録表」や「引っ越しのやることリスト」を、プログラミング不要でGoogle検索の中に作れるようになります。本記事では、この「自分専用ツール」をAIに作らせるための頼み方を解説します。

## ターゲット
- 毎日同じ情報を検索したり、メモ帳にコピペして管理している人
- アプリを新しくインストールしたり使いこなすのが苦手な人
- Google検索の入力欄を「ツールを作る場所」として使いたい人

## ニュースのポイント
- **Antigravity技術の導入**: GoogleがAIに「その場で見栄えの良いツール（UI）」を作らせる技術を検索に統合。
- **継続的な進捗管理**: 1回の検索で終わりではなく、後から戻ってきて更新できる「自分専用の管理画面」が作れる。
- **リアルタイム連携**: 地図や天気、最新のレビューなどを取り込んだ「生きたツール」が完成する。

## プロンプト案の方向性
- **「〜用のツールを作って」という直球の指示**: 検索窓に「私のための〜管理ツールを作って」と入力する際のコツ。
- **必要な項目を指定する**: 「カレンダー、チェックリスト、予算表を入れて」と、具体的に欲しいパーツを伝える方法。
- **初心者のための「育て方」**: 一度作ったダッシュボードに「これも追加して」と話しかけて改良していくステップ。
