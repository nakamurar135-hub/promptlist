# ネタ詳細: 【初心者向け】AIが「勝手にやってくれる」時代へ！LINEヤフーの新機能『Agent i』で面倒な調べ物・予約を丸投げするプロンプト術

## 1. 基本情報
*   **日付**: 2026-04-22
*   **ターゲット**: 初心者（PCやスマホの標準AI、LINEやYahoo! JAPANを日常的に使っているレベル）
*   **トピック**: LINEヤフー発表のAIエージェント「Agent i」

## 2. 記事のコンセプト
2026年4月に発表されたLINEヤフーの最新AI「Agent i」を使って、これまで「自分で調べて、自分で決めて、自分で予約する」という手間をAIに「丸投げ」する新しい体験を紹介します。「AIは質問に答えるもの」から「AIは代わりに動いてくれるもの」への変化を初心者に伝えます。

## 3. 主な内容（プロンプトのポイント）
*   **「実行（Agent）」の体験**: 「週末、鎌倉に行きたいんだけど、おすすめのカフェを調べて予約もお願いできる？」といった、単なる検索を超えた「頼み方」を紹介。
*   **「視覚（Vision）」の活用**: 冷蔵庫の中身を写真で撮って「これで何が作れる？」と聞くだけで、Agent i がレシピ提案から必要な買い出しリストまで作成してくれる流れを解説。
*   **「日程調整」の自動化**: 「友達とランチしたいから空いてる日を探して」と、LINEでのやり取りをAIが仲介するエージェント機能のプロンプト例を提示。

## 4. 想定される読者のメリット
*   スマホ一つで、面倒な「調べ物」や「予約作業」から解放される。
*   LINEやYahoo! JAPANという使い慣れたアプリから、迷わずAIを使いこなせる。
*   「最新のAI」を身近な便利ツールとして実感できる。
