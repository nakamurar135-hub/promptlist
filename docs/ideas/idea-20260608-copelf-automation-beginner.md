# 【初心者向け】もう「クリック」すら不要？ブラウザ操作AI『Copelf』でルーチンワークを自動化するプロンプト術
## 概要
ウェブブラウザ上での定型作業にうんざりしていませんか？2026年4月29日に発表されたブラウザ操作AI「Copelf」は、ユーザーの指示に基づいてウェブサイト上でのクリック、入力、スクロールなどの操作を自動で行います。ITやAIに疎く、PCに備え付けのCopilotやChatGPTぐらいしかAIを知らない初心者でも、「目的」を伝えるだけで日々のルーチンワークを自動化できるプロンプトの書き方を、具体的な事例を交えて解説します。
## ターゲット
- PCでの定型作業をAIに任せて効率化したい初心者ユーザー
- 毎日同じウェブサイトで情報を入力したり、クリックしたりする作業が多い方
- AIを使って業務効率を上げたいが、プログラミング知識がない方
## 記事のポイント
1. **Copelfの基本**: Copelfがどのようにブラウザを操作するのか、その仕組みを分かりやすく解説。
2. **「目的達成型」プロンプトの書き方**: 具体的な操作手順ではなく、「何をしたいか」をAIに明確に伝えるプロンプトのコツ。
3. **ルーチンワーク自動化の事例**: オンラインフォームへの自動入力、特定情報の定期的な収集、ウェブサイトの巡回など。
4. **安全な利用方法**: AIにブラウザ操作を任せる際の注意点や、予期せぬ動作を防ぐためのヒント。
## プロンプト例
- 「毎日午前9時に〇〇証券のウェブサイトにアクセスし、ログイン後、保有銘柄の株価をスプレッドシートに記録してください。」
- 「毎週月曜日の朝に、競合他社のウェブサイトを巡回し、新製品情報をまとめて私にメールで報告してください。」
- 「このオンラインフォームに、私の名前、メールアドレス、住所を自動で入力して送信してください。」
- 「特定のキーワードでGoogle検索を行い、上位10件の検索結果のタイトルとURLをリストアップしてください。」
