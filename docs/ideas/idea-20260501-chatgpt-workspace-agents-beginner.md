# ネタ案: 【初心者向け】チームの「共通ルール」をAIに教えるだけ！ChatGPT『Workspace Agents』でルーチンワークを自動化するプロンプト術

## 1. ターゲット
*   ITやAIに詳しくない一般の会社員
*   チームでの定型作業（日報、議事録、問い合わせ対応など）に追われている人
*   ChatGPTを個人で使っているが、チームでの活用法がわからない人

## 2. ニュースの背景
OpenAIが2026年4月に発表した「Workspace Agents」は、チームや組織全体で共有できるAIエージェントを数分で構築できる機能です。これまでのGPTsよりも、チームの権限管理や複雑なワークフローへの対応が強化されており、個人のプロンプト術をチームの「標準装備」に昇華させることができます。

## 3. 記事の構成案
*   **導入**: 「あの人のやり方」をAIに覚えさせる！チーム全員が「デキる人」になる新機能
*   **機能解説**: 『Workspace Agents』って何？（難しい設定不要で、チームのルールを読み込ませるだけで動く「共有のAI部下」）
*   **プロンプト術**: 
    *   「私たちのチームの書き方」を教える「スタイル・インジェクション」プロンプト
    *   「過去の事例」を参照して答えさせる「ナレッジ・コネクト」プロンプト
*   **具体例**: 
    *   カスタマーサポートの一次回答案をチームのトーン＆マナーで自動生成
    *   バラバラな日報をチーム指定のフォーマットに自動整形
*   **まとめ**: プロンプトは「個人」から「チーム」の資産へ

## 4. 初心者へのメリット
*   一度「チームのルール」をプロンプト（指示書）として設定すれば、PC操作が苦手なメンバーも「いつものChatGPT」に話しかけるだけで、正確な成果物を得られる。
*   「どう指示すればいいかわからない」という初心者の悩みを、チーム共通のエージェントが解決してくれる。
