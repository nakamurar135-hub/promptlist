# 2026-04-15: 【初心者向け】もうプロンプトを打ち直さない！Chromeの『Skills』でAIを「自分専用」に育てる術

## 概要
「毎回同じ指示を入力するのが面倒」「どんなプロンプトだったか忘れてしまう」という初心者の悩みを、Google Chromeの新機能『Skills』で解決するガイド。
よく使う定型文を保存し、スラッシュ（/）一つで呼び出すことで、AI活用を劇的に楽にする方法を解説します。

## ターゲット
- 毎日同じようなメールの返信や要約をAIに頼んでいる人
- プロンプトをメモ帳に保存しているが、いちいちコピペするのが面倒な人
- PCのブラウザ（Chrome）で調べ物をすることが多い事務職や学生

## 記事のポイント
- **『Skills』とは？**: ChromeのサイドパネルにあるGeminiに、自分のお気に入りの指示（プロンプト）を名前をつけて保存できる機能。
- **使い方は「/（スラッシュ）」を打つだけ**: 保存したスキルは、チャット欄に「/」を入力するだけでリストアップされ、瞬時に呼び出し可能。
- **初心者におすすめの「保存すべきスキル」例**:
    - **「要約して」**: 「今開いているページの内容を、3つのポイントで短くまとめて」
    - **「メール下書き」**: 「このページの内容を参考にして、丁寧な報告メールの下書きを書いて」
    - **「優しく解説」**: 「難しい用語を、ITに詳しくない人にも分かるように専門用語抜きで説明して」
- **「自分専用AI」にするコツ**: 一度うまくいったプロンプトをその場で保存する習慣をつけるだけで、AIがどんどん使いやすくなるメリットを強調。
