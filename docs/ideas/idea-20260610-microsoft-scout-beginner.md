# 【初心者向け】AIがあなたの「秘書」になる！Microsoft Scoutで会議準備・スケジュール調整を自動化するプロンプト術

## 概要
Microsoft Build 2026で発表された、個人向けAIエージェント「Microsoft Scout」の活用ガイドです。
ITに疎い初心者でも、PCに備え付けのCopilotを通じて、AIに「会議の準備」や「スケジュールの調整」を丸投げする方法を解説します。

## ターゲット
- PCに標準搭載されているCopilotぐらいしかAIを知らない初心者
- 毎日の会議準備やメールのやり取り、スケジュール調整に追われているビジネスパーソン
- 「AIに何を頼めばいいかわからない」と感じている層

## ネタのポイント
- **「丸投げ」の実現**: 自分でカレンダーを確認したり資料を探したりする手間を、AIエージェントに任せる体験。
- **PC標準機能の延長**: 新しいアプリをインストールすることなく、いつものWindowsやTeams、Outlookの中で完結する。
- **指示の具体例**: 「明日の会議の準備をしておいて」という抽象的な指示を、AIがどう解釈して動くのかをプロンプト例で示す。

## プロンプト例
- 「明日のA社との会議に向けて、これまでのメールのやり取りと関連資料をまとめて要約しておいて。」
- 「来週の午後にBさんと30分打ち合わせしたいんだけど、お互い空いている時間を探して仮押さえしておいて。」
