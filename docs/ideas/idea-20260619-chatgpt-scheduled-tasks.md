# ネタ：【初心者向け】AIが「予約」した時間に仕事する！ChatGPTの新機能『Scheduled tasks』活用プロンプト術

## 概要
2026年6月に発表されたChatGPTの新機能「Scheduled tasks（予約タスク）」にフォーカスしたガイド。
これまでは「今すぐ」の回答しか得られませんでしたが、これからは「明日の朝にメールの下書きを届けて」「毎週月曜にニュースを要約して」といった予約が可能になります。
IT初心者が「AIを自分の秘書のように使いこなす」ための第一歩として、具体的な予約の仕方を伝授します。

## ターゲット
- ChatGPTを使っているが、毎回同じことを聞くのが面倒だと感じている初心者。
- 朝の忙しい時間や、定期的な報告業務を少しでも楽にしたいと考えている人。
- 「プロンプトをいつ打てばいいか」というタイミングの悩みから解放されたい人。

## 記事のポイント
1. **「今すぐ」から「予約」へ！AIが勝手に動く新習慣**：指定した時間にAIが回答を用意してくれるメリットを解説。
2. **魔法の言葉は「〇〇時に〜して」**：特別な設定画面を使わなくても、会話の中で自然に予約できるプロンプト術。
3. **活用シーン：あなたの毎日をAIがサポート**：
    - **朝のブリーフィング**：「毎朝8時に、今日の天気と主要なニュースを3行でまとめて」
    - **締め切り前のリマインド**：「明日の15時に、提出予定のレポートの構成を再確認して」
    - **定期的な学習**：「毎週土曜の午後に、今週学んだ英単語のテストを出して」
4. **「Scheduled」ページで安心管理**：予約した内容をいつでも確認・修正できる安心感を強調。

## プロンプト例
- 「明日の朝9時に、今日やり取りしたメールの内容を整理して教えて」
- 「毎週月曜日の午前中に、先週の私のチャット履歴から『来週やるべきこと』をリストアップして」
- 「今日の夕方18時に、夕食の献立案を3つ提案して」
