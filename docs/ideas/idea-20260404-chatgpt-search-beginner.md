# 2026-04-04: ググるより速い！ChatGPTの「検索機能（Search）」で最新情報を引き出すプロンプト術

## 概要
「AIは古い情報しか持っていない」という初心者の思い込みを覆す、ChatGPTの最新「検索機能（Search）」の活用ガイド。
検索エンジンで複数のサイトを見比べる手間を省き、AIに「今、この瞬間」の情報を正しく調べさせるためのコツを、PC標準のChatGPT利用シーンに合わせて解説します。

## ターゲット
- ニュースや天気、株価などを調べる際、いまだにブラウザの検索窓（Google等）しか使っていない初心者
- ChatGPTを使ってみたが「2023年までの情報しかありません」と言われて諦めてしまった人
- ITに疎く、複数のウェブサイトから情報を取捨選択するのが苦痛な人

## 記事のポイント
- **「ChatGPT Search」とは？**: 従来のAIの弱点だった「最新情報」を、AIが自らネットを検索して回答する機能。出典（ソース）が明示されるため、情報の信頼性も確認しやすいことを紹介。
- **初心者がやりがちな「もったいない」聞き方**: 「今のニュースを教えて」といった漠然とした問いかけではなく、検索を起動させるためのキーワードの入れ方を伝授。
- **コピペで使える検索プロンプト例**:
    - 「今日の東京の天気を調べて、午後の外出に傘が必要か教えて」
    - 「新しく発売されたiPhoneの評判を、複数のレビューサイトからまとめて」
    - 「今週末に都内で開催される、初心者向けのAI勉強会を3つ探して」
- **「ググる」との使い分け**: 自分でサイトを探したい時はGoogle、答えをパッと知りたい時はChatGPT Search、という賢い使い分けを提案。
