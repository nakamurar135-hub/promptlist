# 【初心者向け】AIが「自分専用」の秘書になる！Copilotの『個人用設定』活用プロンプト術

## 概要
Microsoft Copilotに追加された「個人用設定（カスタム指示）」機能を活用し、毎回同じ説明（自分の立場、好みの文体、回答の長さなど）を繰り返さなくても、常に自分に最適な回答が返ってくるようにする設定ガイド。

## ターゲット
- PCに備え付けのCopilotをたまに使うが、回答が一般的すぎて「物足りない」と感じている初心者。
- 毎回「短くまとめて」「敬語で」などと指示を追加するのが面倒だと感じている人。

## プロンプトのポイント
- 「個人用設定」に登録しておくべき3つの要素（自分の役割、理想の回答スタイル、避けてほしい表現）。
- 初心者でもコピペで使える「自己紹介テンプレート」。
- 設定した内容が反映されているか確認するためのテスト用プロンプト。
