# 【中級者向け】AIエージェントと作る！Manusを活用した「爆速Webサイト構築」実践ガイド

## 概要
AIエージェント『Manus』のWeb開発機能を最大限に引き出し、設計からデプロイまでを最短で完結させるための実践的なプロンプト術とワークフローを解説します。

## ターゲット
- Web開発の基礎知識があり、AIを使って効率化したい中級者
- アイディアを素早く形にしたいプロダクトマネージャーやデザイナー

## キーワード
Manus, AI Agent, Web Development, React, Tailwind CSS, Automation

## プロンプト例
「Next.jsとTailwind CSSを使用して、モダンなポートフォリオサイトを作成してください。以下の機能を備えている必要があります：
1. ダークモード対応
2. レスポンシブデザイン
3. GitHub Actionsによる自動デプロイ設定の提案
また、SEO最適化のためのメタタグ設定もコードに含めてください。」

## 活用ステップ
1. **要件定義の対話**: Manusに作りたいサイトの概要を伝え、技術スタックの提案を受ける。
2. **コンポーネント生成**: 特定のUIパーツ（ナビゲーション、ヒーローセクション等）を個別に指示して精度を高める。
3. **SEO・OGP最適化**: Manusのスキルを活用し、検索エンジンやSNSで映える設定を自動生成させる。
4. **デプロイと検証**: 生成されたコードの動作確認と、公開手順の自動化を行う。
