# 【初心者向け】キーボード入力はもういらない？Gemini搭載の次世代音声入力『Rambler』で「話すだけ」書類作成術
## 概要
2026年5月のGoogle I/Oで発表された「Rambler」は、Androidのキーボードアプリ「Gboard」に統合された革新的な音声入力機能です。従来の音声入力とは異なり、Gemini Intelligenceが「あー」「えー」といった不要な言葉を自動で削除し、話の文脈を汲み取って完璧な文章に整えてくれます。PCやスマホの文字入力が苦手な初心者でも、独り言を言う感覚でメールや日記、メモを完成させることができます。
## ターゲット
- キーボードやフリック入力が遅くて、文章を作るのが億劫な初心者
- 会議のメモやアイデア出しを、手を動かさずに終わらせたい人
- 「話すように文章を書きたい」けれど、自分の話し言葉に自信がない人
## 記事のポイント
1. **魔法の音声入力「Rambler」**: 従来の音声入力との違い（文脈理解と自動修正）を解説。
2. **「独り言」を「公的な文章」へ**: 支離滅裂な話し言葉を、プロンプト一つで丁寧なメールや報告書に変換するコツ。
3. **句読点や改行もおまかせ**: 声のトーンや間（ま）をAIが判断して、読みやすいレイアウトにする方法。
4. **スマホ一台で完結**: 外出先や移動中に、Geminiに「口頭で」指示を出してタスクを整理する活用術。
## プロンプト例
- 「今から話す内容を、取引先に送る丁寧なメールの形式に整えて。要件は『打ち合わせの延期』で、理由は『急な体調不良』って感じで適当に話すから直して」
- 「日記を書きたいんだけど、今日あったことをバラバラに話すから、一つの心温まるストーリー風にまとめて。箇条書きじゃなくて文章にしてね」
- 「さっきの会議の録音データ（またはリアルタイム入力）から、決定事項と次にやるべきこと（ToDo）だけを抜き出してリストにして」
