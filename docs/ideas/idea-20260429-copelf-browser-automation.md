# 2026-04-29: 【初心者向け】もう「クリック」すら不要？ブラウザ操作AI『Copelf』でルーチンワークを自動化するプロンプト術

## 概要
2026年4月に登場した、プロンプト不要でブラウザ操作を自動化できるAI「Copelf（コペルフ）」。これまで専門知識が必要だった「Webサイトからのデータ収集」や「定型的な入力作業」を、初心者でもAIに丸投げできる方法を解説します。

## ターゲット
- 毎日同じWebサイトをチェックして情報をコピペしている事務職の方
- ブラウザでの繰り返し作業が面倒だと感じているPC初心者
- 「RPA」や「マクロ」という言葉に難しさを感じて諦めていた人

## ネタのポイント
- **「録画」するだけでAIが学習**: 複雑な指示を書く代わりに、一度だけ自分の操作をAIに見せる（録画する）だけで、次からは「いつものやって」で通じる手軽さ。
- **自然言語での指示**: 録画した操作に対して、「このデータをExcelにまとめて」「新着情報があったらメールして」と付け加えるだけで自動化が完了する点。
- **安全な自動化**: AIが勝手に操作するのが怖い初心者向けに、実行前に「何をするか」を確認させるステップを入れるコツ。

## プロンプト例
- 「さっき録画した手順で、競合他社の新製品価格をチェックして、スプレッドシートに追記しておいて」
- 「毎日朝9時に、このニュースサイトから『AI』に関する記事だけをピックアップしてSlackに送って」
