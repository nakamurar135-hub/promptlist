# 【初心者向け】ネットがなくてもAIが使える？Google Chromeの新機能『組み込みAI』活用プロンプト術
## 概要
2026年5月27日、GoogleはChromeブラウザにAIを直接組み込んだ「Prompt API」の安定版をリリースしました。これは、クラウド上の巨大なAIにアクセスするのではなく、あなたのPCの中でAI（Gemini Nano）が動く仕組みです。ネットが不安定な場所でも動作し、何より「自分のデータが外に送られない」という究極のプライバシー保護が特徴です。ブラウザそのものが賢くなる、新しいAIの形を解説します。
## ターゲット
- セキュリティやプライバシーが心配で、AIに仕事の情報を入れるのをためらっている方
- 外出先や移動中など、ネット環境が不安定な場所でもAIを活用したい方
- ブラウザの「右クリック」感覚で手軽にAIの恩恵を受けたい初心者
## 記事のポイント
1. **「組み込みAI」とは**: PCのパワーを使ってブラウザ内でAIを動かす、次世代の仕組み。
2. **プライバシーの安心感**: データをGoogleに送らずに処理するため、社外秘情報の要約などにも最適。
3. **オフラインでも動作**: 飛行機内や地下でも、文章の校正や翻訳、要約が止まらない。
4. **初心者のための準備**: 自分のPCで動くかどうかを確認するチェックリストと、簡単な設定方法。
## プロンプト例
- 「この長いニュース記事を、3行で要約して。重要な数値は必ず含めて」
- 「今書いているこのメールの文章、もっと丁寧なビジネス敬語に直して。誤字脱字もチェックして」
- 「（オフライン環境で）この英文の意味を日本語で教えて。専門用語は分かりやすく噛み砕いて」
