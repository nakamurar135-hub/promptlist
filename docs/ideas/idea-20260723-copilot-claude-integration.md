# 【初心者向け】AIの「得意不得意」を使い分け！Copilotの新機能でClaudeとGPTを切り替えるプロンプト術

## 概要
Microsoft CopilotにAnthropic社のAIモデル「Claude」が統合されました。これにより、従来のGPTモデルだけでなく、文章作成や論理的思考に定評のあるClaudeをCopilot内で直接利用できるようになります。初心者が「どのAIに頼めばいいか」迷わないよう、それぞれの強みを活かした指示の出し方を解説します。

## ターゲット
- PCに備え付けのCopilotを使っているが、回答の質に満足していない初心者
- 「ChatGPT」以外のAI（Claudeなど）の名前は聞いたことがあるが、使い分けがわからない方
- プロンプトを工夫して、より人間らしい自然な文章をAIに書いてほしい方

## 導入のメリット
- **最適なAIの選択**: 事務作業はGPT、クリエイティブな執筆はClaudeといった使い分けが1つの画面で完結。
- **回答精度の向上**: AIモデルを切り替えるだけで、同じ指示でもより納得感のある回答が得られる。
- **最新機能の先取り**: Microsoftの最新アップデートを使いこなし、日常業務の効率を最大化できる。

## ステップ（導入ガイドの構成案）
1.  **新機能の確認**: Copilot画面での「モデル切り替え」ボタンの見つけ方
2.  **Claudeが得意なこと**: 感情豊かなメール作成や、複雑な文章の要約を頼む時のプロンプト
3.  **GPTが得意なこと**: データ分析や、最新のWeb情報を踏まえた調査を頼む時のプロンプト
4.  **魔法の切り替え指示**: 「この文章をClaudeの視点でリライトして」など、モデルを意識した指示のコツ
