# 【初心者向け】「いつものCopilot」がもっと賢くなる！Microsoft 365の『Claude』切り替えプロンプト術

## 概要
2026年に入り、Microsoft 365 CopilotでOpenAIのモデルだけでなく、Anthropicの高性能AI『Claude』が選択可能になりました。
「AIの回答がなんだか不自然」「もっと人間らしい文章を書いてほしい」と感じている初心者に向けて、モデルを『Claude』に切り替えるだけで回答の質が劇的に変わる体験を提案します。
設定の変更方法から、Claudeの得意分野（自然な文章作成、複雑な文脈の理解）を活かした初心者向けプロンプト術を解説します。

## ターゲット
- PCに備え付けのCopilotを使っているが、回答が機械的だと感じている初心者。
- WordやOutlookで、より自然な日本語の文章を作りたい人。
- AIモデルの違い（GPTとClaude）を難しく考えず、とにかく「良い回答」が欲しい人。

## 記事のポイント
1. **「モデル選び」は「得意な人を選ぶ」感覚で**：数学や検索に強いGPTと、文章表現や共感力に強いClaudeを、初心者向けに分かりやすく比較。
2. **切り替えはワンクリック**：Copilotの設定画面から簡単にモデルを変更できる手順を図解。
3. **Claudeが本領を発揮する「お願いの仕方」**：
    - 「冷たい印象を与えないメールの断り方」
    - 「読者の心に響くブログの導入文」
    - 「複雑な事情を汲み取った相談」
4. **初心者向け「Claude専用」プロンプトの型**：
    - 「〜という背景があるんだけど、角が立たないように〜と伝えて」など、文脈を重視するClaudeへの頼み方。

## プロンプト例
- 「（Claudeを選択して）取引先への打ち合わせ延期のメールを、申し訳なさが伝わるような丁寧な言葉で書いて。」
- 「この長い会議の議事録を、後から読んだ人が当日の雰囲気を思い出せるような自然な文章で要約して。」
- 「新しい趣味を始めたいんだけど、私の今の生活スタイルに合わせて、無理なく続けられる提案を優しく教えて。」
