# 2026-07-19: 【中級者向け】AIが「部下」を指揮する時代へ！Metaの最新モデル『Muse Spark 1.1』によるマルチエージェント導入ガイド

## 概要
Metaが2026年7月9日に発表した『Muse Spark 1.1』は、単なる高性能AIではなく、複数の「サブエージェント」を自律的に管理・指揮する能力に特化した次世代モデルです。100万トークンの広大なコンテキストウィンドウを活かし、複雑な長時間のワークフローを並列処理で完結させることが可能になりました。

本記事では、Muse Spark 1.1を「メインエージェント」として据え、複数のツールやサブエージェントを使いこなして業務を自動化する、中級者向けの高度な活用法を解説します。

## Muse Spark 1.1の核心：マルチエージェント指揮能力
1. **サブエージェントへの動的委任**: 1つの指示からタスクを分解し、コーディング担当、リサーチ担当、データ分析担当などのサブエージェントへ並列に指示を出します。
2. **「スクリプト vs 操作」の最適選択**: 自動化が速い場合はコードを書き、UI操作が必要な場合は直接クリックするという、コンピュータ操作の最適化を自律的に行います。
3. **100万トークンの記憶容量**: 大規模なプロジェクトのコードベースや大量のドキュメントを一度に読み込み、文脈を失わずに長時間のタスクを実行します。

Meta Model API（パブリックプレビュー）を利用し、既存のSaaSや社内ツールとMuse Spark 1.1を連携させるための基本的な環境構築手順を紹介します。

### 3. 実践プロンプト：プロジェクト・オートメーション
