# ネタ：【初心者向け】AIが「自分専用の家庭教師」に！Gemini『Study Notebooks』で苦手分野をゼロにするプロンプト術

## 1. ターゲット
*   資格試験や仕事の勉強をしたいが、どこから手をつければいいか分からない初心者。
*   分厚い参考書を買っても、三日坊主で終わってしまう人。
*   子供の勉強を教えたいが、自分も理解できておらず困っている親世代。

## 2. 元ネタニュース
*   2026年6月、GoogleがGeminiアプリ内に『Study Notebooks（学習ノート）』機能を導入。
*   ノートや資料をアップロードすると、AIが「どこが理解できていないか」をクイズ形式で診断してくれる。
*   個人の学習スタイルに合わせたオーダーメイドのレッスンを作成し、進捗を管理するダッシュボードも搭載。

## 3. 記事の方向性
*   「AIに教わる」のではなく「AIと一緒に学ぶ」という新しい学習体験を提案。
*   手元のメモや写真をアップするだけで、自分だけの「魔法の参考書」ができる感動を伝える。
*   初心者が挫折しないための、AIへの「褒められ方」や「励ましてもらい方」を含むメンタル面でのプロンプト活用。

## 4. プロンプトのポイント
*   **「診断クイズ」の依頼**: 「私が理解できていない部分をあぶり出すクイズを5問出して」という指示。
*   **「たとえ話」で理解する**: 難しい概念を「カレーの作り方に例えて」など、身近なものに置き換えさせる術。
*   **「今日の目標」をAIと決める**: 学習ダッシュボードを活かすための、無理のないスケジュール作成プロンプト。

## 5. 既存ネタとの差別化
*   `idea-20260718-gemini-notebook-advanced-usage.md`（Gemini Notebook）は中級者向けの「外部脳・資料分析」だが、本件は初心者の「基礎学習・教育」に特化。
*   `idea-20260413-gemini-dynamic-visualizer.md`（シミュレーター生成）は図解がメインだが、本件は「体系的な学習プロセス」をサポート。
