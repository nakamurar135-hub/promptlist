# 【中級者向け】Manusを「外部ツール」と連携させて最強の自動化環境を構築するプロンプト術
## 概要
Manusは単体でも強力ですが、GitHubやGoogle Workspace、外部APIと連携させることで、その真価を発揮します。本記事では、Manusを使って外部サービスを操作し、プロジェクト管理やデータ同期を自動化する実践的なテクニックを解説します。
## キーポイント
- GitHub CLI (gh) を使ったリポジトリ操作の自動化
- Google SheetsやDriveとのデータ連携
- 外部API（OpenAI, Anthropic等）をManus経由で呼び出すワークフロー
## ターゲット
- 開発ワークフローを効率化したいエンジニア
- 複数のツールを横断して業務を行うディレクター
## 想定プロンプト
「GitHubの特定リポジトリからIssueを取得し、その内容を要約してGoogle Sheetsに自動追記してください。また、重要度が高いものについてはSlack（または代替手段）で通知を送るためのスクリプトを作成し、実行してください。」
