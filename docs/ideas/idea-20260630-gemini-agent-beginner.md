# 【初心者向け】AIが勝手に動いてくれる！Google Gemini 3.5の『エージェント機能』超入門プロンプト術

## 概要
2026年6月に一般公開された「Gemini 3.5」の目玉機能である「エージェント機能」を、ITに疎い初心者向けに解説するガイド。
これまでのAIは「質問に答える」だけでしたが、最新のGeminiは「Gmailで返信して」「Googleカレンダーに予定を入れて」といった、複数のアプリをまたいだ「お願い」を、たった一言のプロンプトで実行してくれます。
「プロンプトを工夫する」のではなく「やりたいことをそのまま言う」だけで済む、新しいAIの使い方を提示します。

## ターゲット層
- 複数のアプリ（メール、カレンダー、マップ等）を行ったり来たりするのが面倒な人
- PCやスマホの操作自体を「AIにやってほしい」と思っている初心者
- 難しいプロンプトエンジニアリングは覚えたくないが、便利さは享受したい人

## 記事の構成案
1. **「聞くAI」から「動くAI」へ：Gemini 3.5の衝撃**
   - 2026年6月、Geminiは「秘書」になった。
   - あなたの代わりに手を動かしてくれる「エージェント」という考え方。
2. **魔法の一言！「丸投げプロンプト」の実例**
   - 「来週の旅行の予定を立てて、カレンダーに入れておいて」
   - 「このメールの内容を要約して、関係者に返信の下書きを送って」
3. **初心者が失敗しないための「許可」の出し方**
   - AIが勝手に動くのが怖い人への安心設定ガイド。
4. **まとめ：2026年は「プロンプトを書かない」のが正解**
