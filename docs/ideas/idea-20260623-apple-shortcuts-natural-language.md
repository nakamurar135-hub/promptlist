# ネタ：【初心者向け】iPhoneの「ショートカット」が魔法の杖に！自然言語で自動化プロンプト術

## 1. ターゲット
*   ITに疎く、iPhoneの「ショートカット」アプリを難しそうだと避けてきた初心者
*   PCのCopilotやChatGPTを少し触ったことがあり、言葉で指示することには慣れ始めている層

## 2. 元ネタニュース
*   WWDC 2026にて発表されたiOS 27の新機能。
*   Shortcuts（ショートカット）アプリがAI（Apple Intelligence）により自然言語での作成に対応。
*   「家に帰ったら照明をつけて、お気に入りのプレイリストを流して」といった言葉だけで、複雑な自動化設定が構築可能に。

## 3. 記事の方向性
*   「プログラミングのようなパズル」だったショートカットが、「話し相手への頼み事」に変わったことを強調。
*   初心者が日常で使える「魔法のフレーズ（プロンプト）」を具体例とともに紹介。
*   Apple IntelligenceとSiriの連携による、画面操作不要の自動化体験を提案。

## 4. プロンプトのポイント
*   **具体性**: 「何を」「いつ」「どうするか」を自然な日本語で伝えるコツ。
*   **連携**: 写真、メール、カレンダーなど、iPhone標準アプリを組み合わせる指示の出し方。
*   **修正**: AIが作ったショートカットが少し違う時の「言葉での直し方」。
