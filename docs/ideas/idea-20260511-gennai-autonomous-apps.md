# 2026-05-11: 【中級者向け】「源内」に学ぶ！プログラミング不要で自律型AIアプリを自作する実務プロンプト術

## 概要
日本政府が18万人の職員に配布を開始した政府専用AI「源内（Gennai）」の新機能に焦点を当てたガイドです。500以上の業務を自律化させる政府の取り組みから、非エンジニアが「AIエージェント」を自作し、複雑な事務作業や予算資料作成を自動化するための具体的なプロンプト・テクニックを学びます。

## ターゲット
- 自社・自組織にAIエージェントを導入したいと考えている中級者
- プログラミング知識はないが、特定の業務フローを自動化する「アプリ」を作りたい方
- 行政や大企業のAI活用事例を実務に取り入れたい方

## 記事の構成案
1. **はじめに**: 政府が18万人に配布する「源内」の衝撃。自律型AIが標準になる未来
2. **「源内」流・業務アプリ構築法**: 指示だけでコードを書かずにツールを作る「ノーコード・エージェント」の概念
3. **実践プロンプト術**:
   - 複雑な事務規定やマニュアルを「ナレッジ」として読み込ませる方法
   - 複数のステップ（データ抽出→照合→書類作成）を1クリックで実行させる連鎖プロンプト
4. **応用事例**:
   - 予算要求資料の自動下書き作成と整合性チェック
   - 問い合わせ内容に基づいたFAQの自動生成と更新
5. **まとめ**: 「源内」のOSS化で見えた、誰もがAI開発者になれる時代の働き方
