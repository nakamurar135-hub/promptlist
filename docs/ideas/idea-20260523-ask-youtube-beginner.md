# 【初心者向け】動画の内容を「聞くだけ」で解決！YouTubeの新機能『Ask YouTube』活用プロンプト術
## 概要
2026年5月のGoogle I/Oで発表された「Ask YouTube」は、動画の内容をAIが理解し、ユーザーの質問に直接答えてくれる画期的な機能です。長いハウツー動画や講義動画を最初から最後まで見る必要はなく、知りたいことだけをピンポイントで聞き出すことができます。本記事では、ITに詳しくない初心者でも、まるで動画の投稿者に直接質問するようにAIを使いこなすコツを解説します。
## ターゲット
- 長い動画を見る時間がない、または必要な箇所を探すのが苦手な方
- YouTubeで学習や問題解決をしようとしている初心者ユーザー
- プロンプトという言葉に馴染みがないが、AIを便利に使いたい方
## 記事のポイント
1. **「Ask YouTube」とは？**: 動画の内容をAIが要約・解析し、チャット形式で質問に答えてくれる機能の紹介。
2. **「知りたいこと」をそのまま伝える**: 専門用語を使わず、日常会話のように質問するだけでOKな点。
3. **該当シーンへの自動ジャンプ**: 回答に関連する動画の再生箇所をAIが教えてくれる便利機能の活用法。
4. **複数の動画を横断した質問**: 関連する複数の動画から最適な情報を抽出して答えてもらう方法。
## プロンプト例
- 「この料理動画で、塩を入れるタイミングと分量を教えて。そのシーンから再生して」
- 「この30分のPC操作解説動画の中で、初期設定について話しているところだけ要約して」
- 「初心者向けのキャンプ動画をいくつか見て、一番安く揃えられるテントを教えて」
