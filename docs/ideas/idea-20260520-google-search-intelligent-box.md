# 【初心者向け】検索の常識が変わる！Googleの最新「インテリジェント検索ボックス」活用プロンプト術
## 概要
2026年5月20日のGoogle I/O 2026で発表された、過去25年で最大規模のアップデートとなる「インテリジェント検索ボックス」の活用ガイドです。従来のキーワード検索とは異なり、AIがユーザーの意図を先読みして入力欄が動的に広がる新機能を使いこなし、テキスト・画像・ファイルを組み合わせた「マルチモーダル検索」を初心者でも簡単に行えるプロンプト術を解説します。
## ターゲット
- PCに備え付けのCopilotやChatGPTを使い始めたばかりの初心者
- 検索キーワードを考えるのが苦手で、知りたいことにたどり着けない人
- スマホやPCの操作に不慣れだが、最新の便利な機能は使ってみたい人
## 記事のポイント
1. **進化した入力体験**: 入力に合わせて広がる検索ボックスと、AIによる質問の組み立て支援機能の紹介。
2. **「なんでも検索」のコツ**: テキストだけでなく、手元の画像やファイルを投げ込んで答えを得る具体的な手順。
3. **会話を続ける検索**: 検索結果の「AIによる概要」から、そのまま自然な対話で深掘りする方法。
## プロンプト例
- 「（旅行のパンフレットの写真をアップして）ここに行くのに一番安くて楽な経路を教えて。あと、近くで評判のいい蕎麦屋さんもリストアップして」
- 「（エラー画面のスクリーンショットをアップして）パソコンがこうなっちゃったんだけど、どうすれば直る？一番簡単な方法から教えて」
- 「来週の町内会の集まりで出すお弁当のアイデアを出して。予算は1000円以内で、高齢の方でも食べやすいメニューがいいな」
