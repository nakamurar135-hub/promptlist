# ネタ：【初心者向け】言葉が「動くマニュアル」に変身！Google検索の新機能『ジェネレーティブUI』活用プロンプト術

## 1. ターゲット
*   ITやAIに疎く、検索しても文字ばかりで理解が進まないと感じている初心者
*   PCのCopilotやChatGPTを調べ物に使っているが、図解やシミュレーションが欲しい層

## 2. 元ネタニュース
*   Google I/O 2026にて発表されたGoogle検索の「ジェネレーティブUI（生成型ユーザーインターフェース）」機能。
*   ユーザーの質問に対し、AIがリアルタイムでインタラクティブな画像、表、グラフ、シミュレーションを組み合わせたカスタムレイアウトをデザインする。
*   例：機械式腕時計の仕組みや宇宙物理学の概念を、視覚的・動的に解説可能。

## 3. 記事の方向性
*   「ググって文字を読む」から「AIに自分専用の図解を作らせる」への変化を強調。
*   初心者が「どうやって動くの？」という素朴な疑問を、AIにビジュアル化させるためのプロンプト術を紹介。
*   静止画の検索結果では分からなかった「仕組み」や「手順」を、動的なシミュレーションで理解する体験を提案。

## 4. プロンプトのポイント
*   **動詞の活用**: 「見せて」「動かして」「シミュレーションして」など、ビジュアル生成を促すキーワード。
*   **視点の指定**: 「初心者にも分かるように」「断面図で見せて」といった、図解の切り口を指定するコツ。
*   **ステップバイステップ**: 複雑な仕組みを段階的に（アニメーションのように）解説させる指示の出し方。

## 5. 既存ネタとの差別化

*   `idea-20260428-google-drive-ai-overview.md`（ドライブのAI概要）は「既存ファイルの要約」だが、本件は「ゼロからのビジュアル構築」に特化。
