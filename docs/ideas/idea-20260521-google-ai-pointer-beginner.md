# 【初心者向け】プロンプトはもう「書かない」！Googleの新機能『AI Pointer』活用ガイド

## 概要
2026年5月のGoogle I/Oで発表された「AI Pointer（AIポインター）」は、マウスポインタで画面上の何かを「指す」だけで、AIがその文脈を理解する画期的な機能です。ITに疎い初心者でも、長い説明（プロンプト）を書く必要がなく、直感的にAIを使いこなすための方法を解説します。

## ターゲット
- PCの操作が苦手で、AIへの指示（プロンプト）をどう書けばいいか悩んでいる人
- CopilotやChatGPTを少し触ってみたが、入力が面倒で挫折した人
- ChromeブラウザやGooglebook（最新PC）を使っている初心者

## 記事のポイント
1. **「AI Pointer」とは？**: 画面上の画像、テキスト、地図などを指して「これについて教えて」「これとこれを比較して」と言うだけで通じる新UIの紹介。
2. **「これ・それ」プロンプト術**: 曖昧な言葉でも、ポインタが指している場所が「文脈」になるため、初心者が陥りがちな「指示不足」が解消される仕組み。
3. **日常での活用例**:
    - ネットショップの靴を指して「これのサイズ違いを探して」
    - 難しいニュース記事を指して「ここを中学生にもわかるように説明して」
    - 地図上の建物を指して「ここへの行き方を教えて」
4. **まとめ**: AIは「対話」から「指差し」の時代へ。
