# ネタ：【初心者向け】PC操作もAIにお任せ！新しくなった『ChatGPT Work』で「AI社員」に仕事を丸投げするプロンプト術

## 1. ターゲット
*   PCの操作（ファイルの整理、データの転記、アプリの起動など）が苦手、または面倒だと感じている初心者。
*   「ChatGPTはチャットするだけ」と思っていて、実際のPC作業にどう結びつければいいかわからない層。
*   「AIエージェント」という言葉は難しいが、自分の代わりにPCを動かしてくれる便利さを体験したい人。

## 2. 元ネタニュース
*   2026年7月10日、OpenAIがデスクトップ版ChatGPTを大幅刷新し、AIエージェント機能「Codex」を統合した『ChatGPT Work』を公開。
*   従来のチャットに加え、ユーザーの許可を得てPC上のファイル操作やブラウザ操作を自律的に行うことが可能になった。
*   利用制限のリセット合戦により、初心者でもより多くのタスクをAIに依頼できる環境が整った。

## 3. 記事の方向性
*   「相談相手」から「実務担当」への進化を強調。
*   初心者が戸惑わないよう、「AIにPCを操作してもらう」際の安全な指示出しと、具体的な依頼方法をステップバイステップで解説。
*   「AI社員」を雇ったような感覚で、日常のルーチンワークを自動化する楽しさを伝える。

## 4. プロンプトのポイント
*   **「やっておいて」を叶える具体的指示**: 「デスクトップにあるExcelファイルを読み込んで、グラフにしてPDFで保存して」「ブラウザでこのサイトを開いて、最新の価格をメモ帳に書き出して」など。
*   **権限確認への対応**: AIが「操作してもいいですか？」と聞いてきた時の、初心者が安心できる確認のポイント。
*   **失敗を防ぐ「小分け」依頼**: 大きな仕事を一気に頼まず、1つずつ確認しながら進めるプロンプトのコツ。

## 5. 既存ネタとの差別化
*   `idea-20260429-copelf-browser-automation.md`（Copelf）はブラウザ操作に特化しているが、本件はデスクトップアプリやファイル操作を含む「PC全体のワークフロー」をChatGPT一つで完結させる点が異なる。
*   `idea-20260330-gpt5-4-agent-mode.md`（おまかせモード）はブラウザ版の機能だが、本件は「デスクトップアプリ」としての強力な連携機能に焦点を当てる。
