# 【中級者向け】複数AIがチームで働く！Claude Opus 4.6『Agent Teams』と100万トークン活用ガイド
## 概要
2026年6月21日、Anthropicの最上位モデル「Claude Opus 4.6」がリリースされました。今回のアップデートの目玉は、複数のAIエージェントが自律的に協力してタスクを完遂する『Agent Teams』機能と、本750冊分に相当する100万トークンの広大なコンテキストウィンドウです。本記事では、これらの中級者向け機能を使いこなし、大規模プロジェクトの管理や複雑なアプリ開発をAIチームに「丸投げ」するプロンプト術を解説します。
## ターゲット
- 大規模なドキュメント群やソースコードを一括で分析・修正したいエンジニア
- 複数の専門知識が必要な複雑なプロジェクトをAIで効率化したいマネージャー
- 最新のAIエージェント機能を実務レベルで導入したい中級ユーザー
## 記事のポイント
1. **Agent Teamsの仕組み**: 1つの指示から複数のサブエージェントが生成され、相互にフィードバックし合いながらゴールを目指す協調動作。
2. **100万トークンの実力**: 従来比4倍の精度向上。大量のPDFやExcel、ソースコードを一度に読み込ませる際の「コンテキスト設計」のコツ。
3. **Office統合の深化**: PowerPointやExcelへの直接出力。型崩れを防ぎ、そのままプレゼンや分析に使える品質で出力させる指示。
4. **自律型開発のワークフロー**: Claude Codeと連携し、要件定義からコーディング、テストまでをエージェントチームに実行させる方法。
## プロンプト例
- 「このリポジトリの全ソースコードとドキュメントを読み込んで。新機能『自動バックアップ』を追加するために必要な変更箇所をAgent Teamsで洗い出し、実装プランを作成して実行して」
- 「過去3年分の市場調査レポート（PDF 20ファイル）をすべて解析して。競合他社の戦略の変遷を時系列でまとめ、今後の自社戦略の提案書をPowerPoint形式で出力して」
- 「この複雑なExcel補助金申請書を完成させたい。Agent Teamsで、私の過去のプロジェクト資料から必要な情報を抽出し、各項目を適切なトーンで埋めて。不足している情報は私に質問して」
