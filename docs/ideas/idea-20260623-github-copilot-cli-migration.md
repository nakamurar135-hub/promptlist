## ネタの概要
2026年6月に発表された、GitHub Copilot for JetBrainsにおける実行基盤の「Copilot CLI」への移行に伴う新機能とパフォーマンス向上の活用術。
ローカルハーネスからCLI基盤へ移行することで、最新モデル（Opus 4.8等）への迅速な対応や、より高度なコンテキスト理解が可能になる。
