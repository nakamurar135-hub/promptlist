# 【初心者向け】「資料が多すぎて読めない」をAIが解決！Googleの無料ツール『NotebookLM』活用プロンプト術

## 概要
2026年6月に新機能が追加され、さらに使いやすくなったGoogleの無料AIノート「NotebookLM」を活用した初心者向けガイド。
ITに詳しくない人でも、手持ちのPDFやメモをAIに読み込ませるだけで、「自分専用の物知り博士」が誕生します。
「この資料の要点を3行で教えて」「これについて質問があるんだけど」といった、日常の「調べる・まとめる」を劇的に楽にするプロンプト（指示）のコツを解説します。

- PCに詳しくなく、ChatGPTも「何を聞けばいいかわからない」と感じている人
