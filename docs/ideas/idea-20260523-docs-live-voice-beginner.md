# 【初心者向け】キーボード入力はもう不要？Googleドキュメントの新機能『Docs Live』で「話すだけ」資料作成術
## 概要
Google I/O 2026で発表された『Docs Live』は、音声だけで文書の作成から編集までを完結できる革新的な機能です。従来の「音声入力」とは異なり、AIがあなたの断片的な「独り言」や「アイディア」を整理し、構成を整えて清書してくれます。タイピングが苦手な方や、文章を考えるのが億劫な初心者でも、スマホやPCに話しかけるだけでプロ並みの書類が作れるようになります。
## ターゲット
- キーボードで文章を打つのが遅い、または苦手な方
- 頭の中にあるアイディアを文章にするのが難しいと感じている方
- PCやスマホに標準搭載されているツールで手軽にAIを試したい初心者
## 記事のポイント
1. **「Docs Live」の衝撃**: 単なる文字起こしではない、AIによる「思考の整理と文書化」機能。
2. **「ブレインダンプ」のすすめ**: 支離滅裂でもいいから思いついたことを全部話すだけで、AIが整えてくれる仕組み。
3. **声で「直す」指示**: 「ここをもう少し丁寧に」「箇条書きにして」といった編集も声だけで完結。
4. **スマホ1台で完結**: 外出先や移動中でも、マイクに向かって話すだけで資料が完成する手軽さ。
## プロンプト例
- （音声で）「来月の町内会の掃除について案内を作って。日時は6月10日の朝9時、場所は公園。雨だったら中止ってことも書いておいて」
- （音声で）「さっき話した内容を、会社の上司に送る報告書の形式に整えて。あと、予算の話はもう少し控えめな表現にして」
- （音声で）「旅行の持ち物リストを作って。子供がいるから、おむつや着替えも忘れずに入れてね」
