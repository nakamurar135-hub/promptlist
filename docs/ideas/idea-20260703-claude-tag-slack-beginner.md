# 【初心者向け】SlackにAIが「同僚」としてやってきた！新機能『Claude Tag』で仕事の「聞き忘れ」をゼロにするプロンプト術

## 概要
2026年6月23日、Anthropicは新機能『Claude Tag』を発表しました。これは、ビジネスチャットツールのSlack上で、AIのClaudeを「チームメンバーの一員」として招待できる機能です。これまではブラウザを開いて質問しに行く必要がありましたが、これからは会話の中で「@Claude」とメンションするだけで、その場の流れを汲み取った回答をくれます。ITに詳しくない人でも、チャット感覚でAIを使いこなすための最初の一歩を解説します。

## ターゲット
- 毎日Slackを使っているが、AIをどう活用していいかわからない初心者
- ブラウザとチャットを行き来するのが面倒で、AI活用が長続きしない人
- チームの会話を要約したり、タスクを整理したりするのをAIに任せたい人

## 構成案
1. **AIは「ツール」から「同僚」へ**: Slackで使える『Claude Tag』とは？
2. **まずは「呼んでみる」だけ**: メンション機能の基本的な使い方
3. **初心者が今日から使える「丸投げ」プロンプト**:
    - 「これまでの会話を3行でまとめて」
    - 「この議論で決まったタスクを箇条書きにして」
4. **「聞き方」のコツ**: 背景情報を教えなくても「その場のログ」を読んでくれるメリット
5. **まとめ**: 2026年は「AIに話しかける」のが当たり前のオフィススキルになる
