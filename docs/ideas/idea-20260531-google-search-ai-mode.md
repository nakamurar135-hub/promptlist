# 【初心者向け】検索が「会話」に変わる！Google検索の新機能『AI Mode』活用プロンプト術

## ネタの概要
Google I/O 2026で発表された、Google検索の「AI Mode」を初心者が使いこなすためのガイド。
従来のキーワード検索ではなく、AIと対話しながら情報を絞り込んでいく新しい検索体験を、PCやスマホの標準機能として活用する方法を解説する。

## 対象読者
- IT・AIに疎く、検索といえば単語を並べることだと思っている初心者
- PCやスマホに標準で付いている機能なら使ってみたいと考えている層

## ニュースのポイント
- Google検索に「AI Mode」が統合され、クエリの長さが従来の3倍に。
- テキストだけでなく、音声や画像を使ったマルチモーダルな検索が標準化。
- Project Astraの技術により、動画ストリームを起点にしたリアルタイムな質問が可能に。

## プロンプトの例
- 「このエラー画面（画像）が出ているんだけど、機械に詳しくない私でもできる直し方をステップバイステップで教えて」
- 「週末に家族で出かける場所を探しているんだけど、5歳の子どもが喜んで、かつ親がゆっくりできる都内の穴場スポットをいくつか提案して。そのあと、それぞれの場所の混雑予想も教えて」

## 期待される効果
- 検索結果のリンクを一つずつ開く手間が省ける。
- 曖昧な悩みでも、AIとの対話を通じて解決策にたどり着けるようになる。
- 「ググる」から「AIに相談する」へのステップアップを促す。
