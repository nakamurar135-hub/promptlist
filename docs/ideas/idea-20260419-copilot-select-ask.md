# 【初心者向け】回答の一部を「選んで質問」！Copilotの新機能でピンポイントに解決するプロンプト術

## 概要
Copilotの回答が長すぎてどこを見ればいいかわからない、あるいは一部だけ詳しく知りたいという初心者の悩みを解決する新機能「テキスト選択（Ask Copilot）」を活用したガイド。

## 背景・ニュースソース
Microsoft 365 Copilot 2026年2月のアップデートにて、Copilotの応答から特定のテキストを選択し、その部分に焦点を当てて質問できる機能が追加された。
[Microsoft 365 Copilot の新機能 | 2026 年 2 月](https://blogs.windows.com/japan/2026/03/16/whats-new-in-microsoft-365-copilot-february-2026/)

## ターゲット層
- ITに疎く、AIの回答が長文だと読むのが億劫になる初心者。
- PCに標準搭載されているCopilotを使い始めたばかりの人。

## プロンプトのポイント
- 「全部」ではなく「ここだけ」を深掘りする方法。
- 選択したテキストに対して「もっと簡単に説明して」「具体例を教えて」と短く指示するだけで、文脈を維持したまま精度の高い回答が得られること。

## 期待される効果
- プロンプトをいちいち打ち直す手間が省ける。
- 回答の「要点」を逃さず、AIとの対話がスムーズになる。
