# 【初心者向け】パワポの中にAIが住み着いた！ChatGPTの『スライド自動生成』プロンプト術
## 概要
2026年5月21日、OpenAIはMicrosoft PowerPoint内で直接動作する公式アドイン「ChatGPT for PowerPoint」をリリースしました。これにより、ブラウザとパワポを行き来する「コピペ地獄」から解放され、チャット欄に指示を出すだけでスライドの構成案作成からテキスト入力、図解の提案までが完結します。無料プランのユーザーでも利用可能な、全ビジネスパーソン必見の新機能です。
## ターゲット
- プレゼン資料作成に時間がかかりすぎて悩んでいる会社員・学生
- AIに興味はあるが、コピペや設定が面倒で挫折した初心者
- PCに備え付けの機能で手軽に効率化を始めたい方
## 記事のポイント
1. **アドインの導入**: パワポの「挿入」メニューから数クリックでChatGPTを呼び出す方法。
2. **「作る・直す・磨く」**: 白紙からのスライド生成だけでなく、既存スライドのブラッシュアップや要約も可能。
3. **外部連携の凄み**: GmailやSharePointのデータから直接スライドを作る「情報の橋渡し」機能。
4. **初心者のための注意点**: AI任せにしない「最終チェック」のポイントと、データの学習設定について。
## プロンプト例
- 「新商品の社内向け発表資料を8枚構成で作って。SharePointにある『2026年度マーケティング戦略.docx』の内容を反映させて」
- 「このスライドの文字が多すぎるから、3つの箇条書きに要約して、視覚的に分かりやすく整えて」
- 「このプレゼン資料を『初めてAIを触る人』向けに、もっと専門用語を避けて優しい表現に書き換えて」
