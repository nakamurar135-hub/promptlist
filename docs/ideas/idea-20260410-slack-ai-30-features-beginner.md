# ネタ：【初心者向け】仕事の「探し物」はもういらない！Slack AIの30個の新機能活用プロンプト術

## 概要
2026年3月末に発表されたSlackの大規模アップデート「30個のAI機能」を、ITに疎い初心者向けに解説するガイド。特に「エンタープライズ検索」や「canvasへのAI組み込み」により、過去のやり取りやファイルを「探す」手間をゼロにするプロンプト（問いかけ）術を紹介する。Slackを単なるチャットから、自分の代わりに仕事のポイントをまとめてくれる「優秀な助手」に変える体験を提案する。

## ターゲット
- 会社でSlackを使っているが、通知が多くて追いきれない、過去の情報を探すのが苦手な初心者。
- 会議の議事録作成や、溜まったメッセージの要約に時間がかかっている層。
- PC操作は慣れているが、AIをどう実務に結びつければいいか分からない事務職や管理職。

## 記事の構成案
1.  **Slackが「AI自動化の拠点」に！**：2026年3月、30個以上の新機能が追加された最大規模のアップデート。
2.  **「検索」から「質問」へ：キーワードを入れなくても見つかる理由**：
    - 「[プロジェクト名]の最新状況」ではなく「先週の会議で決まった納期は何日？」と聞ける。
    - 複数のチャンネルを横断してAIが「答え」をまとめてくれる凄さ。
3.  **初心者でも今日から使える！Slack AI専用プロンプト例**：
    - **【要約・キャッチアップ】**：「このチャンネルで、昨日から今日までの『決定事項』だけを箇条書きで教えて」
    - **【ファイル検索】**：「[ファイル名]の内容を、新入社員にもわかるように3行で説明して」
    - **【議事録・canvas】**：「これまでの会話をもとに、次にやるべきこと（ToDoリスト）をcanvasにまとめて」
4.  **「右クリック」でAIを呼び出す新習慣**：
    - 難しいプロンプトを書かなくても、メニューから「要約」や「書き換え」を選ぶだけでOK。
5.  **AIは「忘れない助手」**：自分の記憶に頼らず、AIに「あの件どうなった？」と聞くことで、心の余裕を作る使い方の提案。
