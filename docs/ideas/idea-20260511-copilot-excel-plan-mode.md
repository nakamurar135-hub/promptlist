# 2026-05-11: 【初心者向け】Excelの「やり直し」がなくなる！Copilotの新機能『Planモード』で失敗しない自動集計プロンプト術

## 概要
2026年5月に発表されたExcel用Copilotの新機能「Plan（プラン）モード」を活用したガイド。AIがいきなり表を書き換えるのではなく、事前に「これからこういう手順で集計します」という計画を提示してくれるため、ITに疎い初心者でも安心して「丸投げ」できる頼み方を解説します。

## ターゲット
- Excelの関数やマクロが苦手で、AIに頼みたいが「勝手に変なことをされそう」で怖い初心者
- 複雑な集計をAIに頼んだ際、結果が正しいかどうかの確認に時間がかかっている事務職
- PCに備え付けのCopilotを、もっと「仕事の相棒」として使いこなしたい人

## ネタのポイント
- **「実行前に確認」の安心感**: AIが提示する手順（プラン）を確認してから実行ボタンを押すという、初心者向けの新しいワークフロー。
- **指示の「言語化」をAIが助けてくれる**: 曖昧な指示に対しても、AIが「こういうことですか？」と具体的な手順を逆提案してくれるメリット。
- **Python連携との組み合わせ**: 高度な分析も「Planモード」を通すことで、中身が分からなくても結果の妥当性を判断しやすくなるコツ。

## プロンプト例
- 「この売上データから、店舗別の月間ランキングを作りたい。まずはどういう手順で計算するか教えて」
- 「在庫リストから期限切れ間近のものを抽出して。Planモードで手順を確認してから実行したい」
