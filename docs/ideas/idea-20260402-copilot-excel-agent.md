# ネタ：Excelの「わからない」をAIに丸投げ！Copilot Excelエージェント超入門

## 概要
2026年3月に発表された「Microsoft 365 Copilot Wave 3」の目玉機能の一つ、Excelエージェントを活用した初心者向けガイド。数式や関数の知識がゼロでも、日本語で「やりたいこと」を伝えるだけで、データの集計・分析・グラフ作成までをAIが代行してくれる「Excel作業の自動化」体験を解説する。

## ターゲット
- 仕事でExcelを使うが、VLOOKUPやピボットテーブルと聞いただけで頭が痛くなる初心者
- PCに備え付けのCopilotは知っているが、Excelの中でどう使えばいいか分からない層
- 「このデータをいい感じにまとめて」という曖昧な指示を形にしたい事務職・営業職

## 記事の構成案
1. **関数を覚える時代は終わった？**：2026年最新「Excelエージェント」の衝撃。
2. **「やりたいこと」を言葉にするだけ**：
    - 「売上を月別に集計してグラフにして」と頼むだけで完成。
    - 複雑な条件（「3月の中で、1万円以上の注文だけ抽出して」）も日本語でOK。
3. **初心者が今日から使える3つの魔法のプロンプト**：
    - 【整理】「この表を読みやすく整理して」
    - 【分析】「このデータから読み取れる特徴を3つ教えて」
    - 【作成】「この数字を元に、会議用の棒グラフを作って」
4. **「Copilotで編集」ボタンを忘れずに**：
    - エージェントを有効化するためのワンステップ。
    - 失敗しないための「データの準備（テーブル化）」のコツ。
5. **AIと一緒に作る安心感**：AIが作った数式を人間が確認する「共同作業」の進め方。
