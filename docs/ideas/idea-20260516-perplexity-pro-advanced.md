# 【中級者向け】リサーチ時間を9割削減！Perplexity Proの『Research Agent』で深掘り調査を自動化するプロンプト術
## 概要
2026年5月15日、Perplexityは「Research Agent」機能を大幅に強化しました。単なる検索結果の要約を超え、複数の情報源をクロスチェックし、矛盾点の指摘や追加調査が必要な項目の提案までを自律的に行うようになりました。本記事では、この新機能を使い倒して専門的なレポートを数分で作成するためのプロンプト術を解説します。
## ターゲット
- 毎日大量の情報を収集・分析する必要があるリサーチャーやアナリスト
- 新規事業の市場調査を効率化したいビジネスマン
- 信頼性の高いソースに基づいた記事を書きたいライター
## 記事のポイント
1. **Research Agentの進化**: 2026年版の強化ポイント（推論能力の向上とソースの重み付け）。
2. **多角的リサーチの指示**: 1つの問いに対して、肯定・否定・中立の3つの視点から調査させる方法。
3. **矛盾の発見と検証**: 複数のニュースソース間で食い違う情報を自動で特定させるテクニック。
4. **構造化レポート出力**: そのまま企画書に使えるMarkdown形式での出力プロンプト。
## プロンプト例
- 「2026年の固体電池市場の動向について、主要メーカー5社の最新プレスリリースとアナリストレポートを比較し、商用化の時期に関する各社の主張の相違点を表形式でまとめて」
- 「Web3.0の現状について、楽観的な見方と批判的な見方の両方を、直近3ヶ月の主要メディアの記事から抽出して要約して。最後に、まだ解明されていない課題を3つ挙げて」
- 「日本の生成AI規制に関する最新の政府方針を、欧州のAI法と比較しながら解説して。特に中小企業への影響に焦点をつけて」
