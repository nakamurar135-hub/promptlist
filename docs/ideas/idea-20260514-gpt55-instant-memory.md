# ネタ：【初心者向け】AIが「あなたのこと」を忘れない！GPT-5.5 Instantの『パーソナル記憶術』プロンプトガイド

## 概要
2026年5月に発表されたChatGPTの新標準モデル「GPT-5.5 Instant」の目玉機能である「Memory Sources（記憶ソース）」を活用したガイド。ITに疎い初心者でも、AIに自分の好みや過去のやり取りを正しく覚えさせ、使えば使うほど便利になる「自分専用AI」に育てる方法を解説する。

## ターゲット
- ChatGPTを使っているが、毎回同じ説明（自分の仕事や好みのスタイルなど）をするのが面倒だと感じている初心者。
- AIが何を根拠に回答しているのか不安で、情報の出所を透明にしたい層。
- 「AIを育てる」という感覚を体験してみたい、PC操作に不慣れなユーザー。

## ニュースのポイント
- 2026年5月5日に発表されたChatGPTの新しい標準モデル「GPT-5.5 Instant」。
- 新機能「Memory Sources」により、回答の根拠となった過去のチャット、保存済み設定、アップロードファイル、連携済みアプリ（Gmail等）をユーザーが視覚的に確認・管理可能。
- 記憶の削除や修正が容易になり、プライバシーをコントロールしながらパーソナライズを強化できる。

## プロンプトの方向性
- 「これからは私の好みの文章スタイルを覚えておいて」といった、記憶を促す直接的なプロンプト。
- 「今の回答は、どの情報を参考にしたの？」と聞き、Memory Sourcesを確認して回答の精度を上げる対話術。
- 誤った記憶を「それは違うから忘れて」と修正し、AIの「癖」を自分好みに調律するコミュニケーション。

## 既存ネタとの差別化
- 既存の「ChatGPT Skills」は特定の「機能」を覚えさせるものだが、本ネタは「個人の文脈や記憶」の管理に焦点を当てる。
- 従来の「パーソナライズ」よりも、情報の透明性（どこから引用したか）とユーザーによる制御（忘れてもらう）が強化されている点を強調。
- 最新モデル「GPT-5.5 Instant」のスピードと精度を活かした、ストレスのない日常使いを提案する。
