# 【初心者向け】「さっきの作業、何だっけ？」をAIが解決！Mac向けCodexの新機能『Chronicle』活用プロンプト術

## 概要
2026年4月に発表されたMac向けChatGPTアプリ（Codex）の新機能「Chronicle（クロニクル）」を、ITに疎い初心者向けに解説するガイド。デスクトップ上で行った過去の作業（ブラウザ閲覧、ファイル編集、チャットのやり取りなど）をAIが「文脈」として記憶し、曖昧な指示で呼び出したり、その続きを依頼したりできるプロンプト術を紹介する。

## ターゲット
- 複数のアプリを行き来して作業していると、何をしていたか忘れてしまう初心者
- 「あの時見た資料」や「あのメールの内容」を探すのに時間がかかっている人
- 備え付けのCopilotなどは知っているが、自分のPC内の作業とAIが繋がっていないと感じている層

## 記事のポイント
- **「あなたの作業」をAIが録画・記憶する**：Chronicleが実現する「デスクトップの記憶」という新常識。
- **「検索」ではなく「相談」で過去を呼び出す**：
    - 「昨日作ってた旅行の計画、どこまでやったっけ？」
    - 「さっきメールで送られてきた会議のURLを教えて」
- **「続き」をAIに丸投げするプロンプト**：
    - 「さっきのブラウザの調べ物を、このWordに3行でまとめて」
    - 「さっきのZoom会議の内容を、Slackに報告しておいて」
- **プライバシーと安心設定**：初心者が不安に思う「ずっと見られている」ことへの対策と、記録の停止方法。
