# 2026-07-16: 【初心者向け】ボタン一つで「次の作業」をAIが予知！Microsoft 365の新機能『Dynamic Action Button』活用術

## 概要
2026年6月から7月にかけてMicrosoftがWordやExcel、PowerPointに導入した「Dynamic Action Button（ダイナミック・アクション・ボタン）」を、AIへの指示（プロンプト）が思い浮かばない初心者向けに解説します。画面の右下にひっそりと現れるこのボタンは、あなたの作業状況をAIが読み取り、「次にやりたいこと」を先回りして提案してくれます。自分でプロンプトを書かなくても、ボタンを押すだけで資料が完成に近づく、最も簡単なAI活用法を紹介します。

## ターゲット
- Copilotを使いたいが、何を指示すればいいかわからず結局使っていない人
- Wordで文章を書いている時や、Excelで表を作っている時に「もっと楽にできるはず」と感じている事務職の人
- プロンプトを検索してコピペするのが面倒な、効率化を求める初心者

## 記事のポイント
- **「考える」をAIに任せる**: 執筆中の文章なら「要約」、作成中の表なら「グラフ化」など、状況に合わせてボタンの中身が変わる仕組みを解説。
- **「右下の魔法」を見逃さない**: 編集画面の邪魔にならず、必要な時だけ賢い提案をしてくれるフローティングボタンの使い方。
- **初心者がボタンを「育てる」プロンプト術**:
    - **【Wordで】**: 「この段落をもう少しプロっぽく書き直して」という提案をボタンから選び、理想のトーンに調整してもらう方法。
    - **【Excelで】**: 「データの傾向を分析して」という提案ボタンを押し、出てきた分析結果をそのままシートに反映させる手順。
- **「指示待ち」から「選ぶだけ」へ**: プロンプトを1から書くのではなく、AIが提示した選択肢から「正解」を選ぶだけで仕事が進む快感を伝える。
