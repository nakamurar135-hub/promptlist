# 【初心者向け】センス不要！PowerPointに内蔵された最新AI『MAI-Image 2.5』で「伝わるスライド画像」を作るプロンプト術

## 概要
Microsoftが2026年6月のBuild 2026で発表した自社開発AI「MAI」シリーズ。その中でも、すでにPowerPointに搭載されている画像生成AI『MAI-Image 2.5』が話題です。外部の難しい画像生成ツールを使わなくても、スライド作成中に「こんな画像が欲しい」と入力するだけで、プロ級の素材が手に入ります。デザインセンスに自信がない初心者が、言葉だけで資料を華やかにするコツを解説します。

## ターゲット
- PowerPointで資料を作る際、いつもフリー素材探しに時間を取られている初心者
- 画像生成AIに興味はあるが、Midjourneyなどの難しいツールは使いこなせない人
- 「指示の仕方がわからない」せいで、AIからイメージ通りの画像が出てこない人

## 構成案
1. **パワポの中に「専属絵師」がいる？**: 最新AI『MAI-Image 2.5』の凄さ
2. **ボタンひとつで起動**: どこからAIを呼び出すのか、基本操作を解説
3. **初心者が失敗しない「3要素プロンプト」**:
    - 「何が（主役）」＋「どんな風に（スタイル）」＋「どこで（背景）」
    - 具体例：ビジネスマン ＋ 水彩画風 ＋ オフィス
4. **「スライドに馴染む」ための微調整術**: 背景を消したり、色味を合わせる指示の出し方
5. **まとめ**: 2026年は画像も「探す」から「その場で作る」時代へ
