# 【中級者向け】自然言語で社内アプリを爆速開発！「ELYZA Works」で実現する非エンジニアの業務自動化

## ネタの概要
2026年4月23日にリリースされた「ELYZA Works」は、自然言語（日本語）で指示するだけで、業務用の生成AIアプリを構築できる画期的なプラットフォームです。
複雑な処理をLLMに直接実行させるのではなく、AIがプログラムを生成して処理を行うことで、Excelの集計や分析、資料生成などを高精度かつ高速に実行可能。プログラミング知識ゼロの中級者が「開発者」になれる新時代のツールを解説します。

## ターゲット
- 毎日の定型業務（Excel集計、レポート作成など）を自動化したいが、プログラミングスキルがない中級者
- 既存のLLM（ChatGPTなど）の出力精度や計算ミスに不満を感じているビジネスパーソン
- 社内独自のAIツールを低コストで素早く立ち上げたい担当者
