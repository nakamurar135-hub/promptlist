# 【中級者向け】iOS/macOSの操作をAIが完全代行！WWDC 2026発表『Siri AI』とApp Intents活用ガイド
## 概要
2026年6月8日のWWDC 2026にて、Appleは次世代のAI「Siri AI」を発表しました。従来のSiriとは異なり、Google Geminiモデルをベースとした強力な推論能力と、アプリの深部まで操作できる「App Intents」との高度な統合が特徴です。本記事では、ユーザーの個人的な文脈（メール、メッセージ、写真等）を理解し、複数のアプリを跨いでタスクを実行させるための、中級者向け自動化テクニックを解説します。
## ターゲット
- iPhone/Macをメインの仕事道具として活用しているプロフェッショナル
- Shortcuts（ショートカット）アプリを使いこなしたい、または挫折した経験のあるユーザー
- Apple Intelligenceの「パーソナルコンテキスト」を安全かつ効率的に活用したい中級者
## 記事のポイント
1. **Siri AIの進化点**: 従来の音声コマンドから、文脈理解に基づいた「自律実行」への転換。
2. **App Intentsの「繋ぎ」の極意**: AIが認識しやすいアプリ操作の構造化と、ショートカットとの連携。
3. **プライバシーとローカル推論**: 秘匿性の高い情報を扱う際の「Private Cloud Compute」の仕組みとプロンプト設計。
4. **マルチステップ・ワークフロー**: 「写真から情報を抽出し、カレンダーに登録し、リマインダーで通知する」といった複合指示の最適化。
## プロンプト例
- 「先週の出張中に撮った領収書の写真から合計金額を計算して、Numbersの『経費精算』シートの最新行に追加して。終わったら経理担当の佐藤さんにメールで送っておいて」
- 「Safariで開いているこのニュース記事の要約を作成して。その後、私の『AI学習ノート』のメモの末尾に追記し、関連するタグを付けて」
- 「来週の月曜日に予定されている会議の資料がメールで届いているか確認して。届いていればPDFをiCloudの『会議用』フォルダに保存し、目次を作成して」
