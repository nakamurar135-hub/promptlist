# 【初心者向け】ネット記事が「教科書」に早変わり！Edge Copilotの『学習モード』で知識を定着させるプロンプト術
## 概要
2026年5月13日、MicrosoftはEdgeブラウザのCopilotに「学習モード」を搭載しました。この機能は、閲覧中のWebページの内容をAIが解析し、単なる要約に留まらず、理解度を確認するための「クイズ」や「フラッシュカード（暗記カード）」を自動生成するものです。ITに詳しくない初心者でも、ブラウザのボタン一つで自分専用の家庭教師を呼び出せるような体験が可能になります。
## ターゲット
- ネットで調べ物をしても、内容が難しくてすぐに忘れてしまう初心者
- 資格試験や趣味の勉強を効率化したいPCユーザー
- 複雑なニュースや解説記事を「要点だけ」ではなく「理解」したい人
## 記事のポイント
1. **家庭教師がブラウザに常駐**: Edge Copilot「学習モード」の概要と起動方法。
2. **「読む」から「解く」へ**: 記事内容から自動で3択クイズを作成させ、アウトプットで覚える方法。
3. **重要用語の自動抽出**: 難しい専門用語をピックアップして、初心者向けの「フラッシュカード」を作る指示。
4. **ステップアップ学習**: 理解度に合わせて、さらに深い内容を質問していくプロンプトの流れ。
## プロンプト例
- 「このページの内容について、私がちゃんと理解できているか確認するための3択クイズを3問出して。正解したら次の問題、間違えたら優しく解説してね」
- 「この記事に出てくる難しい言葉を5つ選んで、小学生でもわかるように説明した暗記カード（フラッシュカード）形式で書き出して」
- 「このニュースの要点を3つに絞って教えて。そのあと、このニュースが私の生活にどう影響するか、具体例を挙げてクイズ形式で質問して」
