# 【中級者向け】「指示」から「ループ」へ！AIエージェントを自律駆動させる『Loop Engineering』実践ガイド

## 概要
従来の単発プロンプト（指示）を卒業し、AIが目標達成まで自律的に思考と修正を繰り返す「ループ（Loop）」を構築・管理するための実践的ガイド。

## 背景・ニュースの要点
- 2026年6月、Claude CodeやOpenAI Codexの活用が進む中で注目されている**「Loop Engineering」**の概念。
- **Heartbeats（定期実行）**, **Crons（スケジュール実行）**, **Hooks（イベント駆動）**, そして最も強力な**Goal-based loops（目標達成型ループ）**の使い分けが重要視されている。
- AIエージェントに「仕事」を任せる際、単発の指示ではなく「自律的なサイクル」を設計することが業務自動化の鍵となっている。

## 中級者向けのポイント
- **目標設定の極意**: AIが無限ループに陥るのを防ぎ、トークン消費を抑えつつ確実に成果を出すための「検証可能な成功条件」の書き方。
- **サブエージェントの連鎖**: メインのループが特定の課題に直面した際、専用のサブエージェントを生成して解決させる「動的階層構造」の構築法。
- **Claude Code / Codex 実践例**: 具体的なツールを用いた、PRレビュー自動化やスキル自己改善ループのコード例。

## 記事の構成案
1. **プロンプトエンジニアリングの次に来るもの**: なぜ「ループ」が必要なのか？
2. **4つのループタイプ徹底解説**: 定期実行から目標達成型まで。
3. **失敗しないループ設計図**: 成功条件（Definition of Done）の定義とコスト管理。
4. **実践：自律型PRレビューエージェントを作る**: Claude Codeを用いた具体例。
5. **まとめ**: 「AIに従業員としての役割を与える」というマインドセットの転換。
