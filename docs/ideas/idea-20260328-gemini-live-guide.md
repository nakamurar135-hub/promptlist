# ネタ：Google Gemini 3.1 Liveで「AIと雑談」から始める、プロンプト不要の対話術

## 概要
2026年3月に発表されたGoogleの最新音声モデル「Gemini 3.1 Flash Live」を活用し、文字入力が苦手なIT初心者でも「話すだけ」でAIを使いこなせるようになるガイド。従来の「プロンプトを書く」というハードルを、スマホでの「会話」に置き換えることで、AI活用の第一歩を支援する。

## ターゲット
- スマホは使えるが、PCでの文字入力や複雑なプロンプト作成が苦手な初心者
- ChatGPTなどのチャット形式に「何を書けばいいか分からない」と戸惑っている人
- 英語学習や家事の合間の相談など、日常生活で手軽にAIを取り入れたい層

## 構成案
1. **「書く」から「話す」へ。2026年、AIはあなたの隣人に。**：
    - 最新のGemini 3.1 Liveが、感情まで理解するようになった驚きの進化。
2. **キーボードはいらない。スマホを耳に当てるだけ。**：
    - Geminiアプリを立ち上げて、マイクボタンを押す。そこから始まるAI体験。
3. **「雑談」を「プロンプト」に変える会話のコツ**：
    - 最初は「こんにちは」からでOK。
    - 「今から〇〇について相談したいんだけどいい？」と許可を取る。
    - AIの返答がズレたら「そうじゃなくて、こういうこと」と口頭で修正する。
4. **日常を劇的に変える「3つの音声活用」**：
    - **英会話の練習**：相手がAIだから、間違えても恥ずかしくない。
    - **冷蔵庫の余り物相談**：料理をしながら、音声だけで献立を決める。
    - **悩み相談・壁打ち**：散歩中に、モヤモヤを話して整理してもらう。
