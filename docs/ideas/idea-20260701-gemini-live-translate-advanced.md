# 【中級者向け】言語の壁が消える日。Gemini 3.5『Live Translate』をビジネス会議の「最強の黒子」にする活用ガイド

## 概要
2026年6月に発表されたGoogle Gemini 3.5の『Live Translate』機能は、単なる翻訳を超え、会話の文脈や専門用語を瞬時に理解し、複数人の対話をリアルタイムで橋渡しします。本記事では、グローバル会議や商談において、AIを単なる「翻訳機」ではなく「文化の調整役」として使いこなすための中級者向けテクニックを解説します。

## ターゲット
- 海外拠点との会議や英語での商談が増えているビジネスパーソン
- 翻訳の精度だけでなく、会話の「テンポ」や「ニュアンス」を重視する中級者
- Google Workspaceと連携した高度な議事録作成・タスク管理を行いたいユーザー

## キーワード
Gemini 3.5, Live Translate, Real-time Translation, Global Communication, Context Awareness, Google Workspace

## プロンプト例
「これからの英日同時通訳において、IT業界の専門用語（特にクラウドネイティブ関連）はそのままカタカナで残して。また、相手が婉曲表現を使った場合は、その意図を汲み取って『要するにこういうこと』という補足を括弧書きで表示して。会議終了後、重要な決定事項だけをGoogleドキュメントにまとめて。」

## 活用ステップ
1. **コンテキストの事前注入**: 会議の資料や過去の議事録をGeminiに読み込ませ、専門用語や背景知識を学習させる。
2. **Live Translateの起動**: モバイル版またはデスクトップ版のGeminiアプリから、双方向リアルタイム通訳を開始する。
3. **動的フィードバック**: 翻訳が不自然な場合、音声やチャットで即座に「もう少しカジュアルに」「結論を先に」と修正指示を与える。
4. **Workspace連携**: 通訳と同時に、重要な発言をNotionやGoogleドキュメントへ自動保存・構造化させる。
