# ネタ：OpenClaw導入ガイド - 「常駐型AI社員」を自分のPCに召喚する

## 概要
2025年末に登場し、2026年3月にOpenAIへの移籍とGitHubスター数30万突破で話題となったオープンソースの自律型AIエージェント「OpenClaw」の導入・活用ガイド。

## ターゲット
- ChatGPTやClaudeのチャット画面でのやり取りに物足りなさを感じている中級者
- 自分のPC上のファイルをAIに直接操作させたい、または外出先からスマホで自宅PCのAIに指示を出したいユーザー

## 記事の構成案
1. **OpenClawとは？**：従来のチャット型AI（受動的）とOpenClaw（能動的・常駐型）の決定的違い。
2. **3つの活用シーン**：
    - 外出先からスマホ（LINE/Discord）で「昨日の資料送って」と指示してファイルを受け取る。
    - 定期的なニュース収集と要約を毎朝自動で受け取る。
    - 自分の記憶（MEMORY.md）を蓄積し、1週間前の文脈を自動で引き継ぐ。
3. **安全な導入ステップ**：
    - APIキーの設定とGatewayの起動。
    - セキュリティリスク（権限の強さ）と、専用マシンやVPN利用による対策。
4. **中級者向けカスタマイズ**：
    - 「スキル（SKILL.md）」の追加による機能拡張（ブラウザ操作、スマートホーム連携）。
