# 【初心者向け】もうコピペは不要！Edgeの『Copilotモード』で複数サイトの情報を一瞬で比較するプロンプト術

## ニュースの概要
2026年5月、Microsoft EdgeのCopilotに「Copilotモード」が正式搭載されました。これは、ブラウザで開いている複数のタブの内容をAIが同時に把握できる機能です。従来のように情報を一つずつコピペしてAIに渡す必要がなくなり、ショッピングの比較や旅行プランの検討が劇的に楽になります。

## ターゲット
- 複数のサイトを見比べるのが面倒だと感じている初心者
- PCでの調べ物をもっと効率化したい人

## 記事のポイント
1.  **「タブをまたぐ」便利さを強調**: 3つの通販サイトを開いたまま「一番安いのどれ？」と聞くだけで解決する体験を伝えます。
2.  **具体的な活用シーン**: 「家電の比較」「ホテルの比較」「ニュースの要約比較」など、日常生活で役立つ例を提示します。
3.  **簡単な始め方**: Edgeのサイドバーからスイッチを入れるだけの、迷わない操作手順を解説します。

## 想定されるプロンプト
「今開いている3つのサイトの商品のスペックと価格を比較して、表にまとめてください。私の用途（例：キャンプで使いたい）に一番合っているのはどれですか？」
