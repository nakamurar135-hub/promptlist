# 【初心者向け】AIと「チーム」で仕事をする時代へ！新機能『Copilot Cowork』で面倒な作業を丸投げするプロンプト術
## 概要
2026年6月16日に一般提供が開始されたMicrosoft 365 Copilotの新機能『Copilot Cowork』の初心者向けガイドです。
これまでのAIは「1対1で質問に答えてくれる相手」でしたが、Coworkは「チームの一員として裏で動いてくれる」エージェントです。
PCに備え付けのCopilotしか知らない初心者でも、自分が寝ている間や他の作業をしている間にAIに仕事を任せる「新しい働き方」を解説します。
## ターゲット
- PCに最初から入っているCopilotやChatGPTをたまに使う程度の初心者
- 複数の人にメールを送ったり、資料を集めたりする「段取り」が苦手な人
- 「AIに任せる」と言われても、具体的に何を頼めばいいかピンとこない層
## ネタのポイント
- **「チャット」から「共同作業」へ**: 自分が指示を出した後、AIが裏で複数のアプリ（メール、カレンダー、Excel）を操作して作業を完遂してくれる。
- **「 Cowork」タブの活用**: 新しくなったCopilot画面の「Cowork」タブから、チームメイトに頼むような感覚で指示を出す方法。
- **「進捗確認」の楽しさ**: AIがどこまで作業を進めたかを確認しながら、最後に人間が「OK」を出すだけの楽ちんワークフロー。
## プロンプト例
- 「来週のプロジェクト会議に向けて、関係者全員の空き時間を調整して、会議通知を送っておいて。」
- 「未読メールの中から、緊急度の高いものだけをピックアップして、それぞれの返信案を作成しておいて。」
- 「このフォルダにある複数の資料を読み込んで、比較表をExcelで作っておいて。」
