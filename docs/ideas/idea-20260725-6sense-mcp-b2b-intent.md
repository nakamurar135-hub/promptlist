# 【中級者向け】AIエージェントに「顧客の購入意欲」を読み取らせる！6sense MCP ServerによるB2B営業自動化ガイド

## 概要
2026年7月、B2Bインテリジェンスのリーダーである6senseが、Model Context Protocol（MCP）サーバーをリリースしました。これにより、ClaudeやChatGPTなどのAIエージェントが、企業の「予測購入ステージ」や「キーワードインテント」などの強力なB2Bデータに直接アクセスできるようになります。

本記事では、中級者向けに、MCPを活用してAIエージェントに「今、どの企業にアプローチすべきか」を自律的に判断させる、次世代の営業・マーケティング自動化ガイドを解説します。

## ターゲット
- MCP（Model Context Protocol）の基本を理解し、実務への応用を考えている中級者
- B2B営業やマーケティングにおいて、AIを活用したリードナーチャリングを自動化したい方
- 外部のインテリジェンスデータとAIエージェントを連携させ、意思決定の精度を高めたい開発者

## 導入のメリット
- **データの民主化**: 専門的なツールにログインすることなく、チャットインターフェースから顧客のインテント（意図）を確認可能。
- **自律的な優先順位付け**: AIエージェントが購入意欲の高い企業を自動でリストアップし、パーソナライズされたメール案を作成。
- **ワークフローの統合**: 6senseの強力なデータと既存のAIエージェント環境を、MCPという標準規格でシームレスに接続。

## ステップ（導入ガイドの構成案）
1.  **6sense MCP Serverのセットアップ**: サーバーのインストールとAPIキーの設定手順。
2.  **インテントデータの取得**: AIエージェントから「特定のドメインの購入ステージ」や「関連キーワード」をクエリする方法。
3.  **自律型営業エージェントの構築**: 取得したデータに基づき、アプローチの優先順位を判定し、最適なメッセージを生成するプロンプト術。
4.  **実務での運用シナリオ**: 毎朝、購入意欲が高まった企業を通知し、ドラフトを作成させる「AI営業アシスタント」の運用。
