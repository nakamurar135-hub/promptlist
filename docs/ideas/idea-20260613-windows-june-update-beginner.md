# 【初心者向け】Windows 11がもっと便利に！2026年6月アップデートの「AI新機能」を使いこなすプロンプト術

## 概要
2026年6月のWindows 11アップデート（KB5094126）で追加された、日常のPC操作を劇的に楽にするAI機能を初心者向けに解説します。特に「Shared Audio（共有オーディオ）」や「Multi-App Camera（マルチアプリカメラ）」など、一見AIと関係なさそうな新機能も、Copilotを通じて直感的に操作できるようになった点に注目し、難しい設定不要で「言葉で指示するだけ」の活用術を紹介します。

## ターゲット
- PCに標準搭載されているCopilotは知っているが、Windowsの設定変更や周辺機器の操作が苦手な初心者
- 「共有オーディオ」などの新機能をどう使えばいいか分からず、宝の持ち腐れになっている方
- プロンプトを「呪文」のように難しく考えている、ITに疎いPCユーザー

## 記事のポイント
1. **「設定」を探すのはもう終わり**: 「音声を共有したい」「カメラを2つのアプリで使いたい」とCopilotに言うだけで、AIが裏側で設定を完結してくれる体験。
2. **2026年6月アップデートの目玉**: 「Shared Audio」で家族と音楽を共有したり、「Multi-App Camera」でWeb会議をしながら別のアプリで顔を映したりする際の「頼み方」。
3. **AIがPCの「通訳」になる**: 専門用語（低レイテンシ、NPUなど）を知らなくても、「動作を軽くして」といった日常語でPCを最適化するコツ。

## プロンプト例
- 「今流している音楽を、Bluetoothで繋いでいる家族のヘッドホンとも同時に共有して（Shared Audioの起動）」
- 「Zoomで会議しながら、別のカメラアプリでも自分の顔を映せるように設定して（Multi-App Cameraの有効化）」
- 「PCの動作が重いから、AIの力を使って今すぐサクサク動くようにして（NPU最適化の指示）」
