# ネタ：【初心者向け】言葉がそのまま「自分専用の掲示板」に！ChatGPTの新機能『Sites』活用プロンプト術

## 概要
2026年6月に発表された、ChatGPT（Codex）の新機能「Sites」にフォーカスしたガイド。
これまではAIの回答をコピペして保存する必要がありましたが、「Sites」を使えば、AIとのやり取りをそのまま「Webページ（ダッシュボード）」として公開・保存できます。
「自分専用のメモ帳」や「家族との共有掲示板」を、プログラミング不要で「言葉だけ」で作る方法をIT初心者に分かりやすく解説します。

## ターゲット
- AIの回答を後で見返したいが、チャット履歴から探すのが大変だと感じている初心者。
- 家族やチームで情報を共有したいが、共有用のページを作るのは難しそうだと感じている人。
- 「Webサイトを作る」という言葉に憧れはあるが、自分には無理だと思っている人。

## 記事のポイント
1. **「チャット」を「ページ」に変える魔法**：AIが作ったまとめを、URLひとつで共有できる「Sites」の凄さを解説。
2. **「Sitesにして」と一言添えるだけ**：難しい操作は一切なし。回答をWebページ形式に変換するプロンプト術。
3. **活用シーン：情報の「置き場所」をAIが作る**：
    - **自分専用ダッシュボード**：「今週の目標と進捗をまとめた『進捗管理サイト』を作って」
    - **家族の旅行計画**：「今度の旅行のスケジュールと持ち物をまとめた『旅行案内ページ』にして」
    - **趣味のまとめ**：「今日調べた美味しいパン屋さんの情報をまとめた『パン屋リスト』をSitesで作って」
4. **URLで簡単共有**：作ったページはURLを送るだけで誰でも見られる（パスワード設定も可能）便利さを強調。

## プロンプト例
- 「今の旅行プランを、家族に見せられるように『Sites』でWebページにして」
- 「今日教えてもらったダイエットの献立と運動メニューを、毎日見られるダッシュボード形式のページにして」
- 「（仕事のメモを渡して）これを整理して、チームで共有できる簡易的な告知ページをSitesで作って」
