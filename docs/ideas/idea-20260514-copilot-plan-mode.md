# ネタ：【初心者向け】AIが勝手に書き換える不安を解消！Excel Copilotの『プラン確認モード』活用術

## 概要
2026年5月にロールアウトされたExcel Copilotの新機能「Plan Mode（プランモード）」を解説するガイド。AIにExcelを操作させるのが「怖い」「何が起きるか不安」と感じている初心者に対し、実行前にAIの計画を確認・修正することで、安心して業務を任せるためのプロンプト術を伝える。

## ターゲット
- 仕事でExcelを使っているが、AIに表をぐちゃぐちゃにされないか心配で手を出せない初心者。
- Copilotに指示を出しても、思い通りの修正にならないことが多く、結局自分で直している層。
- 「AIが何をしようとしているのか」を事前に把握して、一歩ずつ進めたい慎重派のユーザー。

## ニュースのポイント
- 2026年5月にMicrosoft 365 Copilot in Excelで導入された「Plan Mode」。
- 複雑なデータ操作や修正を行う前に、Copilotが「どのような手順で実行するか」をステップバイステップで提示。
- ユーザーはプランを確認し、特定のステップを修正したり、承認したりしてから実行させることが可能。

## プロンプトの方向性
- 「まずはプランを見せて」と指示し、AIの思考プロセスを可視化させるプロンプト。
- 提示されたプランに対して「3番目のステップはこう変えて」と、実行前に細かく軌道修正する対話術。
- Python連携機能と組み合わせ、「高度な分析をプラン付きで実行して」と依頼し、ブラックボックス化を防ぐ方法。

## 既存ネタとの差別化
- 既存の「Excelエージェント」は自動化の「実行」に焦点を当てているが、本ネタは「実行前の合意形成（透明性）」に焦点を当てる。
- 「Think Deeper」はAIの思考力を高めるものだが、Plan Modeは「ユーザーとの作業分担」を明確にするためのインターフェース活用術である。
- 初心者が最も抱きやすい「AIによる予期せぬ書き換え」という恐怖を取り除くための、具体的かつ心理的なアプローチを提案する。
