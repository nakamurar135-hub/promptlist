# ブログ記事作成フォーマット指示書

このドキュメントは、ChatGPT/AIプロンプト活用記事を作成するためのフォーマット指示書です。
AIモデル（Google AI Studio、Claude Code等）に本ドキュメントを参照させることで、統一された記事を生成できます。

---

## 基本設定

### ターゲット読者
- AI・ChatGPT完全初心者
- 専門用語は避け、必ず平易な言葉で説明する
- 初めてプロンプトを使う人でも迷わず実行できるよう配慮

### 記事仕様
| 項目 | 設定値 |
|------|--------|
| 文字数目安 | 5,000字程度 |
| 掲載媒体 | 個人ブログ（S3+CloudFront静的サイト） |
| 収益モデル | Google AdSense + A8.net + もしもアフィリエイト |
| 主要アフィリエイト商材 | ChatGPT Plus、AI関連ツール |

### 文体ルール
| 項目 | 設定値 |
|------|--------|
| 一人称 | 私 |
| 読者への呼びかけ | 皆さん、皆様 |
| 語尾 | です・ます調（落ち着いたトーン） |
| 可変入力箇所の表記 | 【〇〇を入力】 |

## SEO設計

### メインキーワード
- 記事タイトルに含まれるキーワードをそのままメインKWとして扱う
- 例：「ChatGPT ビジネスメール プロンプト」

### 見出し構造（H2/H3設計）
- H2：主要セクションに使用（目次に表示される単位）
- H3：H2内の詳細項目に使用
- 見出しにはメインKWまたは関連KWを自然に含める

### 内部リンク戦略
- 記事末尾に「関連記事」セクションを設置
- 同シリーズの他記事へ相互リンクを張る
- 人気記事まとめへのリンクも含める

## アイキャッチ画像生成指示

記事のアイキャッチ画像は以下の要件でAI生成してください：

### 画像生成プロンプト構成
```
以下の条件でブログのアイキャッチ画像を生成してください：

テーマ: {記事のメインキーワード}
スタイル: モダン、クリーン、プロフェッショナル
色調: 青・白を基調とした信頼感のある配色
要素: 
- {テーマに関連するアイコンまたはイラスト}
- テクノロジー感のある背景
- 日本語テキストは含めない（後から追加するため）
サイズ: 1200x630px（OGP対応）
雰囲気: 初心者にも親しみやすい、とっつきやすいデザイン
```

### 画像ファイル命名規則
`{記事スラッグ}-eyecatch.png`

例：`chatgpt-business-email-prompt-eyecatch.png`

## HTMLテンプレート（S3+CloudFront用）

以下は静的サイト用のHTMLテンプレート参考例です：

```html
<!DOCTYPE html>
<html lang="ja">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="{メタディスクリプション：120字以内でメインKWを含む}">
    <meta name="keywords" content="{メインKW}, {関連KW1}, {関連KW2}">
    
    <!-- OGP設定 -->
    <meta property="og:title" content="{記事タイトル}">
    <meta property="og:description" content="{メタディスクリプション}">
    <meta property="og:image" content="{アイキャッチ画像URL}">
    <meta property="og:type" content="article">
    
    <!-- Twitter Card -->
    <meta name="twitter:card" content="summary_large_image">
    <meta name="twitter:title" content="{記事タイトル}">
    <meta name="twitter:description" content="{メタディスクリプション}">
    <meta name="twitter:image" content="{アイキャッチ画像URL}">
    
    <title>{記事タイトル}</title>
    
    <!-- 構造化データ（JSON-LD） -->
    <script type="application/ld+json">
    {
        "@context": "https://schema.org",
        "@type": "Article",
        "headline": "{記事タイトル}",
        "image": "{アイキャッチ画像URL}",
        "datePublished": "{作成日ISO形式}",
        "dateModified": "{更新日ISO形式}",
        "author": {
            "@type": "Person",
            "name": "{筆者名}"
        },
        "publisher": {
            "@type": "Organization",
            "name": "{ブログ名}",
            "logo": {
                "@type": "ImageObject",
                "url": "{ロゴ画像URL}"
            }
        },
        "description": "{メタディスクリプション}"
    }
    </script>
</head>
<body>
    <article>
        <header>
            <h1>{記事タイトル}</h1>
            <div class="meta">
                <time datetime="{作成日ISO形式}">作成日: {YYYY年MM月DD日}</time>
                <time datetime="{更新日ISO形式}">更新日: {YYYY年MM月DD日}</time>
            </div>
            <img src="{アイキャッチ画像URL}" alt="{記事タイトル}" class="eyecatch">
        </header>
        
        <nav class="toc">
            <h2>目次</h2>
            <!-- 目次はJavaScriptで自動生成、またはビルド時に生成 -->
        </nav>
        
        <main>
            <!-- 記事本文（Markdownから変換） -->
        </main>
        
        <aside class="affiliate-box">
            <!-- ChatGPT Plus等のアフィリエイトボックス -->
        </aside>
        
        <section class="related-posts">
            <h2>関連記事</h2>
            <!-- 関連記事リスト -->
        </section>
    </article>
    
    <!-- Google AdSense -->
    <script async src="https://pagead2.googlesyndication.com/pagead/js/adsbygoogle.js"></script>
</body>
</html>
```

## チェックリスト

記事完成時に以下を確認してください：

### SEO
- [ ] タイトルにメインKWが含まれている
- [ ] H2/H3見出しにKWまたは関連KWが含まれている
- [ ] メタディスクリプションが120字以内でKWを含んでいる
- [ ] 画像にalt属性が設定されている
- [ ] 内部リンクが3件以上設置されている

### コンテンツ
- [ ] 文字数が5,000字前後である
- [ ] プロンプトが4つ（または指定数）含まれている
- [ ] 各プロンプトに「回答例」が添付されている
- [ ] 可変入力箇所が【〇〇を入力】形式で統一されている
- [ ] 初心者向けの平易な表現になっている

### 収益化
- [ ] ChatGPT Plus訴求が2箇所以上ある
- [ ] アフィリエイトリンク設置箇所が明示されている
- [ ] AdSense配置に適切な余白がある

### 技術
- [ ] 作成日・更新日が記載されている
- [ ] OGP設定が完了している
- [ ] 構造化データ（JSON-LD）が設定されている
- [ ] アイキャッチ画像が生成・設定されている
